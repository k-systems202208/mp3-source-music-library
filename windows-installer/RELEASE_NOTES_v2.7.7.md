# 自宅音楽ライブラリ v2.7.7

公開日: 2026-08-04

## 主な変更

- プレイリストを名前と曲順ごと複製
- PCで曲番号をドラッグして並べ替え
- オーナー限定のアルバム表示名変更
- 家族ユーザーを含む認証済み利用者が自分の表示名を変更
- オーナー限定の管理・診断画面と診断JSON保存
- DB整合性、登録曲、最新スキャン、利用者、プレイリスト、バックアップ、保存先を確認

## 権限

- アルバム表示名の変更と管理・診断はオーナーだけが利用できます。
- 表示名は認証済み利用者が自分の名前だけを変更できます。
- プレイリストは所有者本人だけが閲覧、複製、編集、削除できます。

## データ互換性

- DBスキーマは7のままです。
- 既存の曲、利用者、再生状態、お気に入り、スキン、プレイリストを維持します。
- MP3、タグ、ファイル名、フォルダー名は変更しません。

## 更新方法

1. 利用者メニューからDBバックアップを作成します。
2. 起動中の自宅音楽ライブラリを終了します。
3. `MusicLibrary-Setup-2.7.7-x64.exe`を実行します。
4. 旧版をアンインストールせず上書きします。
5. 起動後、管理画面の版が2.7.7であることを確認します。

## セキュリティ

外部利用は引き続きTailscale Serveを前提とします。ルーターのポート開放、DMZ、Tailscale Funnelは使用しないでください。診断JSONにはローカルの保存先が含まれるため、公開場所へ掲載しないでください。
