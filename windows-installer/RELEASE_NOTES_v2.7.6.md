# 自宅音楽ライブラリ v2.7.6

公開日: 2026-08-03

## 主な変更

- 曲名・アーティスト名の表示変更をオーナーだけに許可
- 家族利用者・匿名接続では編集ボタンを非表示
- APIへの直接リクエストもオーナー以外は`403 Forbidden`で拒否
- 「訂正済」バッジと「訂正済のみ」フィルターを削除
- プレーヤーのアーティスト名・アルバム名を該当一覧へのリンクへ変更
- 最大化プレーヤーでも同じリンク操作に対応

## データ互換性

- DBスキーマは7のままです。
- 既存の曲名・アーティスト名の表示変更は維持します。
- MP3、タグ、ファイル名、フォルダー名は変更しません。
- 利用者、お気に入り、再生履歴、スキン、プレイリストを維持します。

## 更新方法

1. 利用者メニューからDBバックアップを作成します。
2. 起動中の自宅音楽ライブラリを終了します。
3. `MusicLibrary-Setup-2.7.6-x64.exe`を実行します。
4. 旧版をアンインストールせず上書きします。
5. 起動後、管理画面の版が2.7.6であることを確認します。

## 確認項目

- オーナー画面だけに曲名・アーティスト名の編集ボタンがある
- 家族利用者と匿名接続には編集ボタンがない
- 「訂正済」の表示と絞り込みがない
- プレーヤーのアーティスト名・アルバム名から一覧へ移動できる
- 既存の再生状態・お気に入り・プレイリストが維持される

## セキュリティ

外部利用は引き続きTailscale Serveを前提とします。ルーターのポート開放、DMZ、Tailscale Funnelは使用しないでください。
