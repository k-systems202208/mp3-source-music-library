# 自宅音楽ライブラリ v2.7.3

v2.7.3では、Tailscale経由で利用するスマートフォンからホーム画面へ追加し、専用アイコンからアプリのように起動できる仕組みを追加しました。

## スマートフォンのホーム画面対応

- iPhone・iPad・Android向けアプリアイコン
- アプリ名「自宅音楽ライブラリ」
- 短縮名「音楽ライブラリ」
- ホーム画面からのstandalone起動
- 起動中画面
- 通信不能時の専用案内
- safe-areaと44px以上のタップ領域
- 縦向き・横向き表示
- 選択中スキンに応じたテーマ色

## ホーム画面追加案内

利用者メニューへ「スマホのホーム画面に追加」を追加しました。

- 現在の接続先URLを表示・コピー
- 自宅PC内のローカル接続、Tailscale経由、通常HTTPを区別
- Tailscale経由ではHTTPS接続であることを表示
- ホーム画面から起動中か、通常ブラウザ表示中かを表示
- iPhone・iPad、Androidそれぞれの追加方法を案内

外出先でも利用する場合は、普段使うTailscale HTTPS URLを開いた状態からホーム画面へ追加してください。

## キャッシュの安全設計

Service Workerが保存するのは、HTML、マニフェスト、アイコン、通信不能時画面などの表示資産だけです。

次はキャッシュしません。

- API応答
- MP3などの音楽ファイル
- SQLite DBとバックアップDB
- アートワーク
- Tailscale・利用者の認証情報

オフライン音楽再生機能ではありません。Wi-FiまたはTailscale接続が必要です。

## 実機確認

- v2.7.2からの上書きインストール
- iPhoneのホーム画面に専用アイコンを追加
- アイコンからアドレスバーのないstandalone画面で起動
- Tailscale経由・HTTPS・ホーム画面起動中の表示
- 保存済み利用者、再生状態、お気に入り、スキンの維持
- スマートフォンでのライブラリホーム表示

## 継続される機能

- ライブラリホーム
- 利用者別の再生回数・最終再生日時・お気に入り
- 6種類の利用者別スキン
- バックアップ・復元
- プレリリース設定を含む新版通知
- Tailscale利用者識別とオーナー関連付け
- 曲名・アーティスト・アルバム検索
- 再生、シーク、シャッフル、リピート

## 更新方法

自宅音楽ライブラリを終了し、`MusicLibrary-Setup-2.7.3-x64.exe`を実行します。v2.7.2をアンインストールする必要はありません。

曲、利用者、お気に入り、再生履歴、スキン、バックアップは維持されます。DBスキーマはv6のままです。
