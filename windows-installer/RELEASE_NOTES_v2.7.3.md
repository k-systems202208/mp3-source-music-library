# 自宅音楽ライブラリ v2.7.3

v2.7.3では、Tailscale経由で利用するスマートフォンから、ホーム画面へ追加してアプリのように起動できる仕組みを追加します。

## 追加内容

- iPhone・iPad・Android向けアプリアイコン
- アプリ名「自宅音楽ライブラリ」、短縮名「音楽ライブラリ」
- ホーム画面からのstandalone起動
- 起動中画面
- スマートフォン向けsafe-areaとタップ領域調整
- 利用者画面から開けるホーム画面追加手順
- 現在の接続先URLの表示・コピー
- 自宅PC内のローカル接続とTailscale経由の表示区別
- 通信不能時の専用案内
- 選択中スキンに応じたブラウザテーマ色

## キャッシュ方針

Service Workerが保存するのは、HTML、マニフェスト、アイコン、通信不能時画面などの表示資産だけです。API応答、MP3、ライブラリDB、バックアップDB、アートワーク、認証情報は保存しません。

オフラインで曲を再生する機能ではありません。Wi-FiまたはTailscale接続が必要です。

## ホーム画面追加時の注意

外出先でも利用する場合は、普段利用するTailscale HTTPS URLをSafariまたは対応ブラウザで開いてからホーム画面へ追加してください。ローカルURLを追加すると、自宅ネットワーク外では開けない場合があります。

## 更新方法

v2.7.2をアンインストールせず、`MusicLibrary-Setup-2.7.3-x64.exe`を上書きインストールします。曲、利用者、お気に入り、再生履歴、スキン、バックアップは維持されます。DBスキーマはv6のままです。
