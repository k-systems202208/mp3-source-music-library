# 自宅音楽ライブラリ v2.7.2

v2.7.2では、機能や画面配置を変えずに、利用者ごとに見た目を着せ替えられるスキン機能を追加しました。

## 6種類のスキン

- ライブラリー：v2.7.1までの標準デザイン
- ミッドナイト：落ち着いた濃紺のダークデザイン
- ネオン：黒地にシアンとマゼンタの発光
- サイバーパンク：黄色とマゼンタを使った端末風デザイン
- キャンディー：ビビッドでカラフルな明るいデザイン
- モノクローム：白・黒・グレーを基調とし、アートワークも画面上で白黒表示

モノクロームの白黒化は表示時だけ行います。元のアートワーク画像は変更せず、別のスキンへ戻すとカラー表示へ戻ります。

## 利用者ごとの保存

- カードを選ぶとその場でプレビュー
- 「適用する」を押した場合だけ保存
- キャンセルすると保存済みの見た目へ戻る
- 再読み込みやアプリ再起動後も設定を維持
- 家族利用者同士の設定を分離
- ローカルオーナーと関連付け済みTailscaleオーナーは同じ設定を使用
- 未識別接続は標準のライブラリーを使用し、設定を保存しない

## デザイン調整

実機プレビューをもとに、次を調整しました。

- 全スキンでホームの統計カードへ背景・枠・文字色を適用
- ミッドナイト、ネオン、サイバーパンクの利用者表示を高コントラスト化
- キャンディーの本文を読みやすい濃色へ調整
- PC・タブレット・スマートフォンでページ全体が横へはみ出さないよう維持
- モノクロームから別スキンへ戻した際のカラー復帰を確認

## スキーマv6

利用者別スキン設定を保存するため、DBスキーマをv6へ更新します。

移行が必要な場合は、処理前に次の専用バックアップを作成して検証します。

```text
Backups\library-pre-v2.7.2-YYYYMMDD-HHMMSS.db
```

バックアップ作成または検証に失敗した場合は、移行を開始しません。既存の曲、利用者、再生回数、お気に入りには触れません。

## 継続される機能

- ライブラリホーム
- 利用者別の再生回数・最終再生日時・お気に入り
- バックアップ・復元画面
- プレリリース設定を含む新版通知
- ローカルオーナーとTailscale本人の安全な関連付け
- 曲名・アーティスト・アルバム検索
- 再生、シーク、シャッフル、リピート

## 更新方法

自宅音楽ライブラリを終了し、`MusicLibrary-Setup-2.7.2-x64.exe`を実行します。v2.7.1をアンインストールする必要はありません。

利用者データとMP3は、アプリのインストール先とは別に保持されます。
