# 自宅音楽ライブラリ v2.6.3

v2.6.2で確認された起動状態判定と停止処理の不具合を修正した安定化リリースです。新機能は追加していません。

## 修正内容

### 起動状態の確認URLを修正

管理画面が、ブラウザ画面のURLへそのまま`/api/health`を追加していたため、次の誤ったURLを確認していました。

```text
http://127.0.0.1:8765/music-library-search.html/api/health
```

v2.6.3では、ページURLからサーバーのルート部分を取り出し、正しい確認先を使用します。

```text
http://127.0.0.1:8765/api/health
```

これにより、管理画面の起動状態表示、ブラウザを開く操作、外部接続設定時の起動確認を安定させます。

### 停止処理の未定義変数エラーを修正

「停止」または起動中の管理画面終了時に、存在しない変数を参照する可能性があった処理を修正しました。停止後は、自動外部接続の待機状態を安全に解除します。

### ブラウザ上の復旧案内を現行版へ更新

旧バッチ版向けの案内を削除し、Windowsインストーラー版の管理画面とスタートメニューを使う案内へ更新しました。


### 発行元表記を修正

Windowsの「インストールされているアプリ」と実行ファイル情報に表示される発行元を、正式な次の表記へ統一しました。

```text
k-systems202208
```

この変更は表示情報のみで、利用者データ、設定、音楽ファイル、データベースには影響しません。

## 再発防止テスト

- ページURLから正しい`/api/health`を生成できる
- ルートURL・クエリ付きURLでも同じ確認先になる
- 停止操作で未定義変数エラーが発生しない
- 停止後の管理画面状態が正しく初期化される
- 旧バッチ版の復旧案内が残っていない

## 更新方法

v2.6.2以前をアンインストールせず、v2.6.3のインストーラーをそのまま実行して上書き更新できます。

次の利用者データは保持されます。

```text
音楽フォルダ設定
library.db
再生回数
表記補正
アートワークキャッシュ
バックアップ
ログ
Tailscale Serve設定
外部接続URL
```

## 対応環境

- Windows 10 64bit
- Windows 11 64bit
