# v2.7.5 RC2 対象範囲

## 修正理由

RC1をiPhoneのホーム画面アイコンから開いた際、本番DBで動作しているにもかかわらず、工程1用の「v2.7.5 機能プレビュー／複製DB」の案内が表示された。また、5個の画面タブのうち「アーティスト」「プレイリスト」が2行に折り返された。

## RC2の修正

- 本番HTMLから工程1用プレビュー案内を完全に除去
- 保存済みURLに`playlistPreview=1`が残っていても起動時に削除
- プレビューURLによるプレイリスト画面の強制表示を廃止
- Service Workerのキャッシュ名を更新し、RC1の画面資産を破棄
- スマートフォンの画面タブを改行禁止に変更
- 日本語タブが1行に収まるようモバイル時の余白を調整
- 専用の回帰試験をビルド工程へ追加

## 維持する機能

- DBスキーマ7と利用者別プレイリスト
- 8,480曲、既存曲ID、利用者状態
- 長いWindowsパス対応
- 起動時オーナー認証
- PWAホーム画面起動
- スキン、お気に入り、再生履歴、バックアップ・復元

## 実機確認項目

- iPhoneのホーム画面アイコンから起動してプレビュー案内が表示されない
- ホーム画面とプレイリスト画面のタブ文字が1行で表示される
- `RC1確認`プレイリストと3曲が維持される
- 3曲の順序、再生、並べ替え、削除操作が正常
- PC側でもプレビュー案内が表示されない
