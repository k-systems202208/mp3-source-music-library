# ライブラリホーム（v2.7.1 工程1）

## 目的

v2.7.0で実装した利用者別のお気に入り・再生回数を活用し、アプリ起動直後に「今すぐ聴きたい曲」へ移動できるホーム画面を追加する。

## 実装内容

- 起動時の初期画面をホームへ変更
- ホーム／曲名／アーティスト／アルバムのタブ構成
- 現在の利用者別の「最近再生した曲」「お気に入り」「よく聴く曲」
- 全利用者共通の「最近追加した曲」
- ライブラリ収録曲数、お気に入り件数、個人再生回数、アートワーク件数
- 曲・アーティスト・アルバム・お気に入りへのショートカット
- ホーム上での再生、お気に入り登録・解除
- 未識別利用者には個人状態を表示しない

## API

`GET /api/home?limit=8`

利用者IDはクエリから受け取らず、サーバーがローカルオーナー認証またはTailscale識別結果から決定する。

レスポンスには次のセクションを含む。

- `recentlyPlayed`
- `favorites`
- `mostPlayed`
- `recentlyAdded`

## レイアウト

- ホーム、ヘッダー、タブ、各セクションを同一のコンテンツ幅へ収める
- ページ全体には横スクロールを発生させない
- 曲カード部分だけを横スクロール可能にする
- PC、タブレット、スマートフォンで親要素を押し広げない

## 確認済み項目

- 自動回帰試験
- ホームDB取得試験
- HTTP API試験
- 利用者分離試験
- UI構造試験
- レイアウト契約試験
- 実データを複製したプレビュー
- ローカルオーナー表示
- 既存のお気に入り・再生回数の表示
- ページ全体の横方向はみ出し解消

## バージョン管理

本工程をmainへ統合する時点では、公開済みv2.7.0のインストーラー・Release・タグは変更しない。実行ファイルとインストーラーのバージョン番号は、v2.7.1のRC作成時に関連ファイルを一括更新する。
