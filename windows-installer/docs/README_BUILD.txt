自宅音楽ライブラリ v2.7.0
ビルド手順
================================

推奨展開先
----------
PyInstallerの長いhook名によるWindowsパス制限を避けるため、
次のような短い場所へ展開します。

C:\ML270Build

ビルド
------
00_build_installer.batを実行します。

自動処理
--------
・Python仮想環境作成
・PyInstaller 6.21.0導入
・全ソース回帰試験
・EXE作成
・空ライブラリでのスモーク試験
・Inno Setupコンパイル
・SHA-256生成
・BUILD_REPORT作成

完成物
------
release\MusicLibrary-Setup-2.7.0-x64.exe
release\BUILD_REPORT_v2.7.0_RC2.txt

RC2について
-----------
RC2は正式公開前のビルド候補名です。
正式製品バージョンは2.7.0です。
RC2でオーナー個人状態統合まで実機合格した成果物を正式公開しました。

注意
----
・ビルド報告確認前にインストーラーを実行しません。
・既存のreleaseフォルダを成果物の正本と誤認しません。
・ビルド失敗時はログを確認し、.venv-buildを無闇に再利用しません。
