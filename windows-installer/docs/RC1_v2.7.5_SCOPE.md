# v2.7.5 RC1 対象範囲

## 目的

利用者別プレイリストを本番DBへ安全に追加し、PCとTailscale接続のスマートフォンから作成・編集・再生できることを実機確認する。

## 対象

- DBスキーマ6から7への移行
- 移行前バックアップ`library-pre-v2.7.5-*.db`
- プレイリストの作成・名称変更・削除
- 曲の追加・重複防止・削除・並べ替え
- プレイリスト全曲再生
- 利用者間の完全分離
- バックアップ・復元のスキーマ7対応
- PC・スマートフォン表示
- v2.7.4までの全機能維持

## 対象外

- プレイリストの共有
- M3U等の外部形式への出力・取込
- 自動プレイリスト
- オフライン再生

## 安全条件

- MP3ファイルやタグを変更しない
- 8,480曲と既存曲IDを維持する
- 利用者、お気に入り、再生状態、スキン、Tailscale関連付けを維持する
- スキーマ更新前バックアップを作成する
