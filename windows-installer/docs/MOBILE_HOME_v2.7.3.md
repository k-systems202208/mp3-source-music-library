# v2.7.3 スマートフォンのホーム画面対応

## 目的

TailscaleのHTTPS接続先をスマートフォンのホーム画面へ追加し、専用アイコンからアプリに近い表示で起動できるようにします。

## アプリ情報

- アプリ名：自宅音楽ライブラリ
- 短縮名：音楽ライブラリ
- 開始画面：ライブラリホーム
- 表示形式：standalone
- 画面方向：縦横対応

## 対応内容

- Web App Manifest
- iPhone・iPad、Android向けアプリアイコン
- maskableアイコン
- 起動中画面
- Service Worker
- 通信不能時の案内画面
- 利用者メニューのホーム画面追加案内
- 現在の接続先URL表示とコピー
- ローカル接続、Tailscale HTTPS、通常HTTPの表示分離
- safe-areaと44px以上のタップ領域
- 6種類のスキンに応じたテーマ色

## 接続表示

- 自宅PC内：自宅PC内のローカル接続／HTTP（このPC内のみ）
- Tailscale：Tailscale経由／HTTPS
- その他のHTTP：HTTP（追加不可）

ホーム画面から起動中の場合は「ホーム画面から起動中」と表示します。

## キャッシュ方針

キャッシュ対象：

- メインHTML
- Web App Manifest
- アプリアイコン
- 通信不能時画面

キャッシュ対象外：

- API応答
- MP3などの音楽ファイル
- SQLite DBとバックアップ
- アートワーク
- Tailscale・利用者の認証情報

オフライン音楽再生機能ではありません。

## 実機確認

- iPhoneのホーム画面へ専用アイコンを追加
- アイコンからstandalone画面で起動
- Tailscale経由、HTTPS、ホーム画面起動中の表示
- 保存済み利用者状態とスキンの維持
- ライブラリホーム、タブ、統計カード、曲カードのスマホ表示

## 対象外

- MP3のオフライン保存
- App Store・Google Playへの公開
- プッシュ通知
- ロック画面の高度な再生操作
- バックグラウンド再生の保証
