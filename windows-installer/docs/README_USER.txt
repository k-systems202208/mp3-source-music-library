自宅音楽ライブラリ v2.7.0
利用ガイド
================================

1. インストール
---------------
MusicLibrary-Setup-2.7.0-x64.exeを実行します。
従来版は通常アンインストールせず上書きします。

2. 初回起動
-----------
スタートメニューの「自宅音楽ライブラリ」を開き、
MP3フォルダを選び、「ライブラリを開始」を押します。
MP3はコピー・変更しません。

3. ローカル利用者
-----------------
管理画面から開いたブラウザはオーナーとして識別されます。
右上に「オーナー（オーナー）」と表示されます。
URLを直接開いてオーナーにならない場合は、
管理画面の「ブラウザで開く」を使用します。

4. 個人状態
-----------
再生回数、最終再生日時、お気に入りは利用者ごとに保存します。
「★ お気に入りのみ」で現在の利用者のお気に入りへ絞り込みます。
利用者を確認できない場合は個人状態を保存しません。

5. Tailscale
------------
「外部接続をかんたん設定」からTailscale Serveを設定します。
正しいURL:
https://PC名.tailnet名.ts.net/music-library-search.html

6. 本人アカウントの関連付け
---------------------------
ローカルオーナーで関連付けコードを発行し、
本人のTailscale画面から送信します。
ローカル側で本人の表示名・ログイン名・統合件数を確認して承認します。
コードやメールアドレスが写った画面を公開しないでください。

7. 利用者管理
-------------
ローカルオーナーは家族利用者を停止・再開できます。
オーナー自身は停止できません。
Tailscale経由オーナーは一覧閲覧のみです。

8. 保存場所
-----------
%LOCALAPPDATA%\MusicLibrary

library.db、Backups、.artwork-cache、Logs、config.json、
remote-url.txt、診断ファイルが保存されます。

9. 注意
-------
・PC停止／スリープ中は利用できません。
・Funnel、ルーターのポート開放は使用しません。
・長いパスのMP3は読み取りエラーになる場合があります。
・市販音源を第三者へ配布する機能ではありません。
