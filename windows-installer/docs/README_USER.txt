自宅音楽ライブラリ v2.7.0
利用ガイド
================================

1. インストールまたは更新
-------------------------
自宅音楽ライブラリが起動中なら停止します。

MusicLibrary-Setup-2.7.0-x64.exeをダブルクリックします。
v2.6.3から更新する場合も、旧版をアンインストールしません。

2. 初回起動
-----------
初めて利用する場合は、MP3フォルダを選択します。

v2.6.3から更新した場合は、初回起動時にデータ移行を行います。
移行前バックアップは次へ作成されます。

%LOCALAPPDATA%\MusicLibrary\Backups

3. ローカル利用
---------------
管理画面の「ライブラリを開始」を押すと、
ローカルオーナーとしてブラウザを開きます。

画面右上に現在の利用者が表示されます。

4. 利用者別機能
---------------
認証済み利用者ごとに、次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り

曲の☆を押すと★になり、お気に入りへ登録されます。
「★ お気に入りのみ」で登録曲だけを表示できます。

5. Tailscale外部接続
--------------------
管理画面の「外部接続をかんたん設定」を使います。

Tailscale経由でアクセスした家族は、
Tailscaleアカウントごとに別の利用者として登録されます。

6. オーナー本人のTailscale関連付け
----------------------------------
ローカル画面で関連付けコードを発行します。
Tailscale側で本人がコードを入力した後、
ローカル画面で表示名とログイン名を確認して承認します。

自動関連付けは行いません。

Tailscale側ですでに再生回数やお気に入りを使用している場合は、
承認画面に統合対象を表示し、確認後にオーナーへ安全に統合します。
異なる評価が設定された曲がある場合は、データを推測せず中止します。

7. 利用者管理
-------------
ローカルオーナーは、利用者一覧を確認し、
オーナー以外の利用を停止・再開できます。

利用者データを誤って失わないよう、完全削除機能はありません。

8. 未識別の接続
---------------
検索と再生はできますが、
再生回数とお気に入りは保存されません。

9. データ保存先
---------------
%LOCALAPPDATA%\MusicLibrary

10. アンインストール
--------------------
Windowsの「インストールされているアプリ」から削除できます。
library.dbなどの利用者データは安全のため残ります。
