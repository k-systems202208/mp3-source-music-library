自宅音楽ライブラリ v2.7.4
利用ガイド
================================

1. インストールまたは更新
-------------------------
自宅音楽ライブラリが起動中なら停止します。

MusicLibrary-Setup-2.7.4-x64.exeを実行します。
v2.7.3以前から更新する場合も、旧版をアンインストールしません。

2. ライブラリホーム
-------------------
起動後はライブラリホームを表示します。

・最近再生した曲
・お気に入り
・よく聴く曲
・最近追加した曲

ホームの曲カードから再生やお気に入り登録ができます。
上部のタブから曲名・アーティスト・アルバム表示へ移動できます。

3. 長いファイルパス
-------------------
Windowsで260文字以上になる深いフォルダーや長いファイル名のMP3も、
v2.7.4からスキャン・検索・再生できます。

ファイル名、フォルダー名、MP3タグは自動変更しません。
DBには従来どおり音楽フォルダーからの相対パスを保存します。

4. スマートフォンのホーム画面へ追加
-----------------------------------
外出先でも利用する場合は、普段使うTailscale HTTPS URLを
スマートフォンで開いてから追加します。

iPhone・iPad:
Safariの共有ボタン → ホーム画面に追加 → 追加

Android:
ブラウザのメニュー → アプリをインストール
またはホーム画面に追加

ホーム画面追加はMP3のオフライン保存を行いません。
自宅PCとTailscaleまたはWi-Fiへ接続できる状態が必要です。

5. スキンの変更
---------------
画面右上の利用者ボタンから「スキンを変更」を開きます。

利用できるスキン:
・ライブラリー
・ミッドナイト
・ネオン
・サイバーパンク
・キャンディー
・モノクローム

「適用する」を押した場合だけ保存します。

6. 利用者別機能
---------------
認証済み利用者ごとに、次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン

7. バックアップ・復元
---------------------
自宅PCのローカルオーナー画面に「バックアップ・復元」があります。
復元は起動中のDBへ直接上書きせず、次回起動時に実行します。

8. 新版通知
-----------
オーナーには、GitHubの公開済みRelease情報
（プレリリース設定を含む）を表示します。
自動ダウンロードや自動インストールは行いません。

9. Tailscale外部接続
--------------------
管理画面の「外部接続をかんたん設定」を使います。
Tailscale経由でアクセスした家族は、アカウントごとに
別の利用者として登録されます。

10. データ保存先
----------------
%LOCALAPPDATA%\MusicLibrary

11. アンインストール
--------------------
Windowsの「インストールされているアプリ」から削除できます。
library.dbなどの利用者データは安全のため残ります。
