自宅音楽ライブラリ v2.7.3
利用ガイド
================================

1. インストールまたは更新
-------------------------
自宅音楽ライブラリが起動中なら停止します。

MusicLibrary-Setup-2.7.3-x64.exeを実行します。
v2.7.2以前から更新する場合も、旧版をアンインストールしません。

2. ライブラリホーム
-------------------
起動後はライブラリホームを表示します。

・最近再生した曲
・お気に入り
・よく聴く曲
・最近追加した曲

ホームの曲カードから再生やお気に入り登録ができます。
上部のタブから曲名・アーティスト・アルバム表示へ移動できます。

3. スマートフォンのホーム画面へ追加
-----------------------------------
外出先でも利用する場合は、普段使うTailscale HTTPS URLを
スマートフォンで開いてから追加します。

画面右上の利用者ボタンから
「スマホのホーム画面に追加」を開きます。

次を確認します。

・接続の種類: Tailscale経由
・通信方式: HTTPS
・表示URL: 普段利用するTailscale URL

iPhone・iPad:
Safariの共有ボタン → ホーム画面に追加 → 追加

Android:
ブラウザのメニュー → アプリをインストール
またはホーム画面に追加

追加後は「音楽ライブラリ」の専用アイコンから起動します。
アドレスバーを表示しないアプリ形式の画面になります。

ホーム画面追加はMP3のオフライン保存を行いません。
自宅PCとTailscaleまたはWi-Fiへ接続できる状態が必要です。

4. スキンの変更
---------------
画面右上の利用者ボタンから「スキンを変更」を開きます。

利用できるスキン:
・ライブラリー
・ミッドナイト
・ネオン
・サイバーパンク
・キャンディー
・モノクローム

カードを選ぶと一時的に画面へ反映します。
「適用する」を押した場合だけ保存します。
キャンセルすると保存済みの見た目へ戻ります。

5. 利用者別機能
---------------
認証済み利用者ごとに、次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン

6. バックアップ・復元
---------------------
自宅PCのローカルオーナー画面に「バックアップ・復元」があります。
復元は起動中のDBへ直接上書きせず、次回起動時に実行します。

7. 新版通知
-----------
オーナーには、GitHubの公開済みRelease情報
（プレリリース設定を含む）を表示します。
自動ダウンロードや自動インストールは行いません。

8. Tailscale外部接続
--------------------
管理画面の「外部接続をかんたん設定」を使います。
Tailscale経由でアクセスした家族は、アカウントごとに
別の利用者として登録されます。

9. データ保存先
---------------
%LOCALAPPDATA%\MusicLibrary

10. アンインストール
--------------------
Windowsの「インストールされているアプリ」から削除できます。
library.dbなどの利用者データは安全のため残ります。
