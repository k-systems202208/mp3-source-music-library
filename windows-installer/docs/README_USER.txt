自宅音楽ライブラリ v2.7.2
利用ガイド
================================

1. インストールまたは更新
-------------------------
自宅音楽ライブラリが起動中なら停止します。

MusicLibrary-Setup-2.7.2-x64.exeを実行します。
v2.7.1以前から更新する場合も、旧版をアンインストールしません。

2. ライブラリホーム
-------------------
起動後はライブラリホームを表示します。

・最近再生した曲
・お気に入り
・よく聴く曲
・最近追加した曲

ホームの曲カードから再生やお気に入り登録ができます。
上部のタブから曲名・アーティスト・アルバム表示へ移動できます。

3. スキンの変更
---------------
画面右上の利用者ボタンから「スキンを変更」を開きます。

利用できるスキン:
・ライブラリー
・ミッドナイト
・ネオン
・サイバーパンク
・キャンディー
・モノクローム

カードを選ぶと一時的に画面へ反映します。
「適用する」を押した場合だけ保存します。
キャンセルすると保存済みの見た目へ戻ります。

モノクロームではアートワークも画面上で白黒表示しますが、
元の画像ファイルは変更しません。別スキンへ戻すとカラー表示へ戻ります。

4. 利用者別機能
---------------
認証済み利用者ごとに、次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン

曲の☆を押すと★になり、お気に入りへ登録されます。
「★ お気に入りのみ」で登録曲だけを表示できます。

5. バックアップ・復元
---------------------
自宅PCのローカルオーナー画面に「バックアップ・復元」があります。

・手動バックアップの作成
・バックアップの検証結果確認
・復元予約
・復元予約の取消

復元は起動中のDBへ直接上書きせず、次回起動時に実行します。
復元直前の状態も自動バックアップされます。
利用者別スキン設定もDBバックアップへ含まれます。

6. 新版通知
-----------
オーナーには、GitHubの公開済みRelease情報
（プレリリース設定を含む）を表示します。

「今すぐ確認」で再確認できます。
自動ダウンロードや自動インストールは行いません。

7. Tailscale外部接続
--------------------
管理画面の「外部接続をかんたん設定」を使います。

Tailscale経由でアクセスした家族は、
Tailscaleアカウントごとに別の利用者として登録されます。

8. オーナー本人の関連付け
-------------------------
ローカル画面で関連付けコードを発行します。
Tailscale側で本人がコードを入力した後、
ローカル画面で表示名とログイン名を確認して承認します。

関連付け済みオーナーは、ローカル側とTailscale側で
再生状態、お気に入り、スキン設定を共有します。

9. 未識別の接続
---------------
検索と再生はできますが、
再生回数、お気に入り、スキンは保存されません。
表示は標準の「ライブラリー」になります。

10. データ保存先
----------------
%LOCALAPPDATA%\MusicLibrary

11. アンインストール
--------------------
Windowsの「インストールされているアプリ」から削除できます。
library.dbなどの利用者データは安全のため残ります。
