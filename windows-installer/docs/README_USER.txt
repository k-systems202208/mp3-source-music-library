自宅音楽ライブラリ v2.7.5
利用ガイド
================================

1. インストールまたは更新
-------------------------
起動中のアプリを終了し、
MusicLibrary-Setup-2.7.5-x64.exeを実行します。

旧版はアンインストールせず上書きします。
schema 6から7への更新前に
Backups\library-pre-v2.7.5-*.dbを自動作成します。

2. ライブラリホーム
-------------------
最近再生、お気に入り、よく聴く曲、最近追加から
続けて曲を選べます。

3. 検索・再生
-------------
曲名、アーティスト、アルバムから検索します。
再生、一時停止、シーク、前後、シャッフル、
全曲リピート、1曲リピートを利用できます。

4. プレイリスト
---------------
「プレイリスト」→「新しいプレイリスト」で作成します。

曲名・アーティスト・アルバム画面の曲カードで
「＋」を押し、追加先を選びます。

できること:
・すべて再生
・名前変更
・プレイリスト削除
・個別再生
・曲順を上／下へ移動
・曲を外す

同じ曲は二重登録されません。
曲を外したりプレイリストを削除しても、
MP3と通常の曲一覧は削除されません。

5. 利用者別機能
---------------
利用者ごとに次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン
・プレイリストと曲順

6. スキン
---------
利用者ボタンから6種類のスキンを選択し、
「適用する」で保存します。

7. スマートフォン
-----------------
TailscaleのHTTPS URLをSafari等で開き、
ホーム画面へ追加します。

PWAはMP3を端末へ保存しません。
自宅PCとTailscaleまたはWi-Fi接続が必要です。

8. 長いパス
-----------
260文字以上の深いフォルダーや長いMP3名に対応します。
ファイル名、フォルダー名、タグは変更しません。

9. バックアップ・復元
---------------------
ローカルオーナーが利用できます。
schema 7ではプレイリストもバックアップ対象です。
復元は次回起動時に実行します。

10. 新版通知
------------
公開済みGitHub Releaseを確認します。
自動ダウンロード・自動インストールは行いません。

11. 保存先
----------
%LOCALAPPDATA%\MusicLibrary

12. アンインストール
--------------------
Windowsのアプリ設定から削除します。
利用者データは安全のため残ります。
