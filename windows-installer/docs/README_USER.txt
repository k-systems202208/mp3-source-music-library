自宅音楽ライブラリ v2.7.5
利用ガイド
================================

1. インストールまたは更新
-------------------------
自宅音楽ライブラリが起動中なら停止します。

MusicLibrary-Setup-2.7.5-x64.exeを実行します。
v2.7.4以前から更新する場合も、旧版をアンインストールしません。

初回起動時にDBスキーマを7へ更新し、
Backupsにlibrary-pre-v2.7.5-*.dbを自動作成します。

2. ライブラリホーム
-------------------
起動後はライブラリホームを表示します。

・最近再生した曲
・お気に入り
・よく聴く曲
・最近追加した曲

ホームの曲カードから再生やお気に入り登録ができます。
上部のタブから曲名・アーティスト・アルバム・プレイリストへ移動できます。

3. プレイリスト
---------------
「プレイリスト」タブを開き、「新しいプレイリスト」で作成します。

曲を追加する方法:
・曲名、アーティスト、アルバム画面を開く
・曲カードの「＋」を押す
・追加先のプレイリストを選ぶ

プレイリスト画面では次を行えます。
・すべて再生
・名前変更
・プレイリスト削除
・曲の個別再生
・曲順を上または下へ移動
・プレイリストから曲を外す

同じ曲は同じプレイリストへ二重登録されません。
曲やプレイリストを削除しても、MP3ファイルと通常の曲一覧は削除されません。

4. 利用者別機能
---------------
認証済み利用者ごとに、次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン
・プレイリストと曲順

家族は自分のプレイリストだけを表示・編集できます。

5. スマートフォンのホーム画面へ追加
-----------------------------------
外出先でも利用する場合は、普段使うTailscale HTTPS URLを
スマートフォンで開いてから追加します。

iPhone・iPad:
Safariの共有ボタン → ホーム画面に追加 → 追加

Android:
ブラウザのメニュー → アプリをインストール
またはホーム画面に追加

ホーム画面追加はMP3のオフライン保存を行いません。
自宅PCとTailscaleまたはWi-Fiへ接続できる状態が必要です。

6. スキンの変更
---------------
画面右上の利用者ボタンから「スキンを変更」を開きます。

利用できるスキン:
・ライブラリー
・ミッドナイト
・ネオン
・サイバーパンク
・キャンディー
・モノクローム

「適用する」を押した場合だけ保存します。

7. 長いファイルパス
-------------------
Windowsで260文字以上になる深いフォルダーや長いファイル名のMP3も、
スキャン・検索・再生できます。

ファイル名、フォルダー名、MP3タグは自動変更しません。

8. バックアップ・復元
---------------------
自宅PCのローカルオーナー画面に「バックアップ・復元」があります。
スキーマ7ではプレイリストもバックアップ対象です。
復元は起動中のDBへ直接上書きせず、次回起動時に実行します。

9. 新版通知
-----------
オーナーには、GitHubの公開済みRelease情報
（プレリリース設定を含む）を表示します。
自動ダウンロードや自動インストールは行いません。

10. Tailscale外部接続
---------------------
管理画面の「外部接続をかんたん設定」を使います。
Tailscale経由でアクセスした家族は、アカウントごとに
別の利用者として登録されます。

11. データ保存先
----------------
%LOCALAPPDATA%\MusicLibrary

12. アンインストール
--------------------
Windowsの「インストールされているアプリ」から削除できます。
library.dbなどの利用者データは安全のため残ります。
