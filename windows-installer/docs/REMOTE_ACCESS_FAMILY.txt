自宅音楽ライブラリ v2.7.0
家族向けTailscale利用ガイド
================================

基本方針
--------
家族ごとに別のTailscaleアカウントを使用します。
オーナーのパスワードを共有しません。

利用
----
1. 家族端末へTailscaleを導入します。
2. オーナーが許可したアカウント／共有方法で接続します。
3. 自宅音楽ライブラリのHTTPS URLを開きます。
4. 右上に本人の利用者名が出ることを確認します。

個人状態
--------
再生回数、最終再生日時、お気に入りは家族ごとに分かれます。
匿名表示の場合は個人状態を保存しません。

オーナー関連付け
----------------
家族アカウントをオーナーへ関連付けないでください。
関連付けは自宅PCのオーナー本人が、本人の外出用Tailscaleプロフィールを
同一人物として統合するための機能です。

利用停止
--------
オーナーは自宅PCから家族利用者を停止・再開できます。
停止しても既存のお気に入りや再生回数は削除しません。

安全
----
・Funnelやルーターのポート開放を使いません。
・URLやTailscale情報をSNSへ掲載しません。
・市販音源を家庭外へ配布しません。
