# バックアップ・復元画面（v2.7.1 工程2）

## 目的

`library.db` のバックアップ作成・検証・復元予約を、ローカルオーナーがブラウザ画面から安全に操作できるようにする。

## 実装内容

- 自宅PCのローカルオーナー専用「バックアップ・復元」画面
- 手動バックアップ作成
- 日次・手動・移行前・オーナー関連付け前・復元前バックアップの一覧
- SQLite `quick_check`、DBスキーマ、収録曲数による検証
- 壊れたDBまたは非対応スキーマを復元候補から除外
- 復元の二段階確認
- 復元予約の取消
- 復元前の自動バックアップ
- 復元結果の表示

## 安全な復元方式

実行中の `library.db` は画面操作から直接上書きしない。

1. 画面から復元対象を予約する
2. アプリを終了する
3. 次回起動時、DBを開く前に予約を処理する
4. 現在のDBを次の名前で保存する

```text
Backups/library-pre-restore-YYYYMMDD-HHMMSS.db
```

5. 予約したバックアップを `library.db` へ復元する
6. 検証・復元結果を保存して画面へ表示する

## 権限制御

バックアップ・復元APIは、自宅PC上で認識されたローカルオーナーだけが利用できる。Tailscale経由のオーナーを含むリモート利用者や一般利用者には表示・実行を許可しない。

## 主なAPI

- バックアップ一覧取得
- 手動バックアップ作成
- 復元予約
- 復元予約取消
- 復元結果取得

各APIはサーバー側でローカルオーナー権限を再確認し、ブラウザから利用者IDや権限を指定させない。

## 確認済み項目

- バックアップ一覧と分類
- 手動バックアップ作成
- SQLite検証
- 非対応DBの除外
- ローカルオーナー限定API
- 復元予約と取消
- 次回起動時の復元
- 復元前バックアップ
- 復元失敗時の保護
- UI構造と二段階確認
- 実運用DB・Backupsを複製したプレビュー
