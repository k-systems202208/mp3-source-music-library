# v2.7.4 正式リリース対象範囲

## 追加・改善機能

- ローカルドライブの260文字以上のWindowsパス
- UNCネットワークパスの長いパス形式
- MP3走査、ファイル情報、ID3タグ、音声情報
- 埋め込み・外部アートワーク
- 移動検出用の内容署名
- MP3のHTTP配信とRangeシーク
- 起動直後のローカルオーナー認証ハンドオフ安定化

## 実機・実データ確認

- v2.7.3からの上書きインストール
- 8,279曲から8,480曲へ更新
- 長いパス201曲をすべて登録
- スキャンエラー0件
- 最長364文字の曲をPCブラウザで再生・シーク
- 既存曲ID、利用者、お気に入り、履歴、スキンを維持
- 起動・終了を3回繰り返し、認証画面停止が再発しないことを確認

## 自動確認

- 長いパスの模擬MP3走査
- タグ・アートワーク・内容署名
- HTTP Range再生
- 実データ読み取り専用プローブ工程
- 複製DBフルスキャン・状態維持工程
- PWA・Tailscale・既存機能の回帰試験
- 起動認証の3回連続ハンドオフ試験

## 変更しないもの

- DBスキーマv6
- MP3と元のアートワーク
- ファイル名・フォルダー名・タグ
- 既存の利用者状態、スキン、バックアップ
- 公開済みv2.7.3タグとRelease

## 対象外

- ファイル名・フォルダー名の自動短縮
- MP3タグや音源ファイルの書換え
- Windows全体の長いパス設定を強制変更する処理
- MP3のオフライン保存
- App Store・Google Play配布

## 正式リリース条件

- 全回帰試験に合格
- v2.7.3からの上書きインストールに成功
- 8,480曲・エラー0件を確認
- 最長364文字の曲の再生・シークに成功
- 起動認証を3回連続で確認
- GitHub Draft Releaseの内容と添付ファイルを確認後、手動で公開
