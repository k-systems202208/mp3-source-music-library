# v2.7.5 正式リリース範囲

公開日: 2026-08-03

## 追加

- 利用者別プレイリスト
- 作成・名称変更・削除
- 曲追加・除外・曲順変更
- 重複追加防止
- 個別再生・全曲再生
- 利用者間の所有権分離
- schema 7
- 移行前自動バックアップ
- schema 7のバックアップ・復元

## RC2で修正

- 本番画面から工程1プレビュー案内を除去
- 保存済みURLから`playlistPreview`を除去
- Service Workerキャッシュ更新
- スマートフォンの5タブを1行表示
- RC1で保存したプレイリスト・曲順を維持

## 実機確認

- v2.7.4から上書き
- 8,480曲
- アートワーク7,708曲
- お気に入り、履歴、再生回数、利用者、スキン維持
- 実運用DBでプレイリスト1件・3曲
- iPhoneのホーム画面アイコンから表示
- RC2上書き後も永続化
- プレビュー案内なし
- タブ1行表示
- 横崩れなし

数値は受入環境の値であり固定上限ではありません。

## 回帰

- schema 5→7
- 起動認証
- Tailscale識別
- 利用者別状態・お気に入り
- スキン
- ライブラリホーム
- バックアップ・復元
- 新版通知
- PWA
- 長いパス
- EXE・インストーラー

## 変更しないもの

- MP3・タグ・ファイル名
- 既存曲ID
- 既存利用者状態
- 公開済み過去タグ・Release
- 履歴文書

## 対象外

- プレイリスト共有
- M3U入出力
- 自動選曲
- MP3オフライン保存
- ストア配布

## 公開状態

v2.7.5の公開完了はユーザー報告で確認済みです。公開後の新版通知画面は本監査資料には含まれていません。
