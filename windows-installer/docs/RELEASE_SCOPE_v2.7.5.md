# v2.7.5 正式リリース対象範囲

## 追加機能

- 利用者別プレイリスト
- プレイリストの作成・名称変更・削除
- 曲の追加・削除・並べ替え
- 同じ曲の重複追加防止
- プレイリスト全曲再生
- 前へ・次へ・シャッフル・リピートとの連携
- PC・スマートフォン表示
- DBスキーマ7
- スキーマ更新前の自動バックアップ

## RC2の改善

- 本番画面に残った工程1用プレビュー案内を除去
- 保存済みURLからplaylistPreviewパラメーターを削除
- Service Workerキャッシュを更新
- スマートフォンの5個の画面タブを1行表示
- RC1で保存したプレイリストと曲順を維持

## 実機確認

- v2.7.4からの上書きインストール
- 8,480曲、アートワーク7,708曲
- お気に入り、再生回数、履歴、利用者、スキンを維持
- 実運用DBでプレイリスト1件・3曲を保存
- iPhoneのホーム画面アイコンからプレイリストを表示
- RC2上書き後もプレイリストと曲順を維持
- プレビュー案内が表示されない
- 5個の画面タブが1行で表示される
- ページ全体の横方向の崩れなし

## 自動確認

- DBスキーマ6から7への移行
- 移行前バックアップ
- プレイリストのDB・API・画面契約
- 利用者間の所有権分離
- 重複追加防止
- 名称変更、削除、曲順変更、全曲再生
- スキーマ7のバックアップ・復元
- PWAキャッシュ、本番表示、スマートフォンタブ
- 長いパス、起動認証、スキン、お気に入り、利用者別状態の回帰試験

## 変更しないもの

- MP3と元のアートワーク
- ファイル名・フォルダー名・タグ
- 既存曲ID
- 既存の利用者状態、スキン、バックアップ
- 公開済みv2.7.4タグとRelease

## 対象外

- プレイリストの共有・共同編集
- M3Uなど外部形式の入出力
- 自動選曲プレイリスト
- MP3のオフライン保存
- App Store・Google Play配布

## 正式リリース条件

- 34項目の回帰・機能試験に合格
- v2.7.4からの上書きインストールに成功
- 8,480曲と既存状態を維持
- 実運用DBでプレイリスト保存を確認
- スマートフォンの本番表示修正を確認
- GitHub Draft Releaseの内容と添付ファイルを確認後、手動で公開
