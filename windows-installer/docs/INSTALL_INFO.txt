自宅音楽ライブラリ v2.7.3
インストール前のご確認
================================

このインストーラーは、自宅音楽ライブラリ v2.7.3を
Windows 10・11（64bit）へ導入します。

インストールまたは更新の前に、
起動中の自宅音楽ライブラリを停止してください。

更新方法
--------
v2.7.2以前をアンインストールせず、v2.7.3を上書きインストールします。

既存のMP3参照先、収録曲、利用者、再生回数、お気に入り、
スキン、表記補正、アートワークキャッシュ、外部接続設定、
バックアップを引き継ぎます。

音源とスマートフォンキャッシュ
------------------------------
・MP3は別の場所へコピーしません。
・MP3音源はインストーラーに含まれていません。
・ホーム画面追加はMP3をスマートフォンへ保存しません。
・API応答、DB、バックアップ、アートワーク、認証情報も
  Service Workerのキャッシュ対象外です。

データ保存先
------------
%LOCALAPPDATA%\MusicLibrary

DBスキーマ
----------
v2.7.3のDBスキーマは6です。v2.7.2から変更ありません。
必要な場合は既存の安全な移行処理と移行前バックアップを使用します。

スマートフォンのホーム画面追加
------------------------------
外出先でも利用する場合は、普段使うTailscale HTTPS URLを
開いた状態からホーム画面へ追加してください。
ローカルURLから追加すると、自宅ネットワーク外で開けない場合があります。

外部接続
--------
Tailscale Serveを使用します。
Tailscale Funnelやルーターのポート開放は使用しません。

アンインストール
----------------
アプリ本体は削除されますが、
%LOCALAPPDATA%\MusicLibraryの利用者データは安全のため残ります。
