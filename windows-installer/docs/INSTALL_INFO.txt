自宅音楽ライブラリ v2.7.5
インストール前のご確認
================================

このインストーラーは、自宅音楽ライブラリ v2.7.5を
Windows 10・11（64bit）へ導入します。

インストールまたは更新の前に、
起動中の自宅音楽ライブラリを停止してください。

更新方法
--------
v2.7.4以前をアンインストールせず、v2.7.5を上書きインストールします。

既存のMP3参照先、8,480曲、利用者、再生回数、お気に入り、
スキン、表記補正、アートワークキャッシュ、外部接続設定、
バックアップを引き継ぎます。

データベース更新
----------------
初回起動時にDBスキーマを6から7へ更新し、
利用者別プレイリスト用の管理テーブルを追加します。

更新前には次のバックアップを自動作成します。

%LOCALAPPDATA%\MusicLibrary\Backups\library-pre-v2.7.5-*.db

MP3、ID3タグ、ファイル名、フォルダー名は変更しません。

プレイリスト
------------
プレイリストは現在の認証利用者ごとに保存します。
別の利用者のプレイリストは表示・編集できません。

プレイリストを削除してもMP3ファイルは削除されません。

データ保存先
------------
%LOCALAPPDATA%\MusicLibrary

主な内容:
・library.db
・利用者別の再生回数、お気に入り、スキン、プレイリスト
・表記補正
・アートワークキャッシュ
・バックアップ
・ログ
・外部接続URL
・新版確認キャッシュ

外部接続
--------
Tailscale Serveを使用します。
Tailscale Funnelやルーターのポート開放は使用しません。

スマートフォンのホーム画面追加はMP3を端末へ保存しません。
API応答、DB、バックアップ、アートワーク、認証情報も
Service Workerのキャッシュ対象外です。

アンインストール
----------------
アプリ本体は削除されますが、
%LOCALAPPDATA%\MusicLibraryの利用者データは安全のため残ります。
