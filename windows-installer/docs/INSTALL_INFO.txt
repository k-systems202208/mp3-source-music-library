自宅音楽ライブラリ v2.7.1
インストール前のご確認
================================

このインストーラーは、自宅音楽ライブラリ v2.7.1を
Windows 10・11（64bit）へ導入します。

インストールまたは更新の前に、
起動中の自宅音楽ライブラリを停止してください。

音源の扱い
----------
・MP3は別の場所へコピーしません。
・利用者が選択した既存フォルダをそのまま参照します。
・MP3音源はインストーラーに含まれていません。

データ保存先
------------
%LOCALAPPDATA%\MusicLibrary

主な内容:
・library.db
・利用者別の再生回数とお気に入り
・表記補正
・アートワークキャッシュ
・バックアップ
・ログ
・外部接続URL
・新版確認キャッシュ

v2.7.0からの更新
----------------
旧版をアンインストールせず、v2.7.1を上書きインストールします。

既存のMP3参照先、利用者、再生回数、お気に入り、表記補正、
アートワークキャッシュ、外部接続設定を引き継ぎます。

v2.6.3以前からの更新
--------------------
初回起動時に必要な場合は、スキーマ5へ移行します。
移行直前に次の専用バックアップを作成します。

%LOCALAPPDATA%\MusicLibrary\Backups
library-pre-v2.7.0-YYYYMMDD-HHMMSS.db

この名称はスキーマ5を導入した版を示すため、v2.7.1でも変更しません。
バックアップに失敗した場合は移行を開始しません。

外部接続
--------
Tailscale Serveを使用します。
Tailscale Funnelやルーターのポート開放は使用しません。

Tailscale経由では、接続したTailscale利用者ごとに
再生回数とお気に入りを分けて保存します。

アンインストール
----------------
アプリ本体は削除されますが、
%LOCALAPPDATA%\MusicLibraryの利用者データは安全のため残ります。
