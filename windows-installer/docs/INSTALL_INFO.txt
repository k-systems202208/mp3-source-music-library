自宅音楽ライブラリ v2.7.2
インストール前のご確認
================================

このインストーラーは、自宅音楽ライブラリ v2.7.2を
Windows 10・11（64bit）へ導入します。

インストールまたは更新の前に、
起動中の自宅音楽ライブラリを停止してください。

更新方法
--------
v2.7.1以前をアンインストールせず、v2.7.2を上書きインストールします。

既存のMP3参照先、収録曲、利用者、再生回数、お気に入り、
表記補正、アートワークキャッシュ、外部接続設定、バックアップを引き継ぎます。

音源の扱い
----------
・MP3は別の場所へコピーしません。
・利用者が選択した既存フォルダをそのまま参照します。
・MP3音源はインストーラーに含まれていません。

データ保存先
------------
%LOCALAPPDATA%\MusicLibrary

主な内容:
・library.db
・利用者別の再生回数、お気に入り、スキン設定
・表記補正
・アートワークキャッシュ
・バックアップ
・ログ
・外部接続URL
・新版確認キャッシュ

スキーマv6への移行
------------------
初回起動時に必要な場合は、利用者別スキン設定を保存する
スキーマv6へ移行します。

移行直前に次の専用バックアップを作成して検証します。

%LOCALAPPDATA%\MusicLibrary\Backups
library-pre-v2.7.2-YYYYMMDD-HHMMSS.db

バックアップ作成または検証に失敗した場合は、移行を開始しません。

外部接続
--------
Tailscale Serveを使用します。
Tailscale Funnelやルーターのポート開放は使用しません。

Tailscale経由では、接続したTailscale利用者ごとに
再生回数、お気に入り、スキン設定を分けて保存します。

アンインストール
----------------
アプリ本体は削除されますが、
%LOCALAPPDATA%\MusicLibraryの利用者データは安全のため残ります。
