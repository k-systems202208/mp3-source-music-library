自宅音楽ライブラリ v2.7.0
インストール前のご確認
================================

このインストーラーはWindows 10／11 64bitへ
自宅音楽ライブラリ v2.7.0を導入します。

音源
----
・利用者が選択した既存MP3フォルダを参照します。
・MP3をコピー、移動、変更しません。
・音源はインストーラーに含まれません。

利用者データ
------------
%LOCALAPPDATA%\MusicLibraryへ保存します。

・library.db（schema 5）
・利用者別再生回数／お気に入り
・表記補正
・利用者・Tailscale識別情報
・アートワークキャッシュ
・バックアップ
・ログ・診断
・外部接続URL

更新
----
従来版をアンインストールせず上書きできます。
起動中のアプリは停止してください。
旧共通状態は初回起動時にオーナーへ移行し、
直前にlibrary-pre-v2.7.0-*.dbを作成します。

外部接続
--------
・Tailscaleは別途公式版を導入します。
・Tailscale Serveを使用します。
・Funnelとルーターのポート開放は使用しません。
・Tailscaleログインは利用者本人が行います。

利用者識別
----------
・自宅PCは管理画面からオーナーとして開きます。
・外部はTailscaleアカウント単位で識別します。
・一般的なパスワードログイン画面はありません。
・識別できない接続では個人状態を保存しません。
