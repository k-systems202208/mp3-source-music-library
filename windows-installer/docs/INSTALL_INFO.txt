自宅音楽ライブラリ v2.7.6
インストール・更新情報
================================

対応:
Windows 10／11 64bit

インストーラー:
MusicLibrary-Setup-2.7.6-x64.exe

更新手順:
1. 利用者メニューからDBバックアップを作成
2. 自宅音楽ライブラリを完全終了
3. インストーラーを実行
4. 旧版をアンインストールせず上書き
5. 起動後、版・曲数・利用者状態を確認

データ保存先:
%LOCALAPPDATA%\MusicLibrary

DB:
library.db
現行スキーマ: 7

schema 6から7への更新:
・プレイリスト用テーブルを追加
・移行前にSQLiteバックアップを作成
・失敗時はロールバック

移行前バックアップ:
%LOCALAPPDATA%\MusicLibrary\Backups\library-pre-v2.7.5-*.db

維持する内容:
・曲IDと検索情報
・利用者と識別情報
・再生回数、最終再生、お気に入り
・スキン
・バックアップ
・MP3とアートワーク

初回確認:
・2.7.6
・8,480曲前後（確認環境）
・アートワーク7,708曲前後（確認環境）
・お気に入り、履歴、スキン
・プレイリストタブ
・起動認証で停止しない
・スマートフォンの5タブが1行
・曲名・アーティスト名の編集がオーナーだけに表示
・プレーヤーのアーティスト名・アルバム名から一覧へ移動

注意:
数値は実機確認値であり固定上限ではありません。
MP3はインストーラーに含まれません。
