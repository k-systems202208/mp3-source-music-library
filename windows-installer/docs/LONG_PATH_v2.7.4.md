# v2.7.4 長いファイルパス対応

## 目的

Windowsの従来のパス長制限により読めなかったMP3を、ファイル名やフォルダー構成を変更せずにスキャン・登録・再生します。

## 対応範囲

- ローカルドライブの長いパス
- UNCネットワークパスの長いパス
- 音楽フォルダーの再帰走査
- ファイルの存在確認、サイズ取得、先頭・末尾読込、シーク
- ID3タグ取得
- Mutagenによる音声情報と埋め込みアートワーク取得
- 外部アートワークの読込とハッシュ取得
- 移動検出用の内容署名
- MP3のHTTP配信
- HTTP Range指定による途中位置再生

## パス表現

Windows内部のファイルI/Oで必要な場合だけ、通常パスを拡張長パス形式へ変換します。

```text
ローカル: \\?\C:\Music\...
UNC:      \\?\UNC\server\share\...
```

DB、API、ブラウザ、ログ表示には通常の相対パスを使用します。

```text
Music/アーティスト/アルバム/曲名.mp3
```

## 変更しないもの

- MP3ファイル
- ID3タグ
- ファイル名
- フォルダー名
- 元のアートワーク
- DBスキーマv6
