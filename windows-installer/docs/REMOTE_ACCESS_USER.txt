自宅音楽ライブラリ v2.7.7
外部接続・スマートフォン利用
================================

前提
----
・自宅PCで自宅音楽ライブラリが起動中
・自宅PCと利用端末にTailscale
・Tailscale ServeのHTTPS URL
・ルーターのポート開放は不要

接続
----
管理画面の「外部接続をかんたん設定」を使います。
表示されたHTTPS URLをスマートフォンで開きます。

利用者
------
Tailscaleアカウントごとに別利用者として識別されます。
次を利用者別に保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン
・プレイリストと曲順

ホーム画面
----------
iPhone／iPad:
Safari → 共有 → ホーム画面に追加

Android:
ブラウザメニュー → アプリをインストール
またはホーム画面に追加

専用アイコンからstandalone表示で起動します。

プレイリスト
------------
スマートフォンでも作成、追加、曲順変更、再生、削除ができます。
同じ利用者で開けばPCと同じプレイリストを表示します。
他の家族のプレイリストは表示しません。

曲情報とプレーヤー
------------------
曲名・アーティスト名の変更はオーナーだけが行えます。
プレーヤーのアーティスト名・アルバム名から該当一覧へ移動できます。

オフライン
----------
MP3、API、DB、バックアップ、アートワーク、認証情報は
PWAキャッシュへ保存しません。

自宅PCまたはTailscaleへの接続がない状態では
音楽を再生できません。

安全上の注意
------------
・Tailscale Funnelを使わない
・URLや認証トークンを公開場所へ貼らない
・端末紛失時はTailscale側で無効化
・家族以外をtailnetへ追加しない
