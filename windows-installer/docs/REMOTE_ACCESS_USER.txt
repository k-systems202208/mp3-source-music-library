自宅音楽ライブラリ v2.7.2
Tailscale外部接続ガイド
================================

外部接続にはTailscale Serveを使用します。
Tailscale Funnelとルーターのポート開放は使用しません。

設定
----
1. 自宅音楽ライブラリを起動
2. 「外部接続をかんたん設定」を押す
3. 必要に応じてTailscaleをインストール
4. 利用者本人がTailscaleへログイン
5. 画面の案内に従ってServe設定を完了

正しいURL形式:
https://PC名.tailnet名.ts.net/music-library-search.html

利用者識別
----------
Tailscale Serveが付与するログイン情報を使い、
接続したTailscaleアカウントごとに利用者を識別します。

家族ごとに次が分かれます。
・再生回数
・最終再生日時
・お気に入り
・スキン設定

オーナー本人の関連付け
----------------------
ローカルオーナーとTailscale側の本人は、
確認コードとローカル側の最終承認で関連付けます。

関連付け後は、ローカル側とTailscale側で
再生状態、お気に入り、スキン設定を共有します。
家族のアカウントを自動でオーナーにすることはありません。

注意
----
・PCがスリープまたは電源オフの時は接続できません。
・自宅音楽ライブラリが停止中は接続できません。
・利用者情報がない接続は未識別になります。
・市販MP3を第三者へ配布する機能ではありません。
