自宅音楽ライブラリ v2.7.0
外部接続ガイド
================================

1. 自宅PCでアプリを起動します。
2. 「外部接続をかんたん設定」を押します。
3. Tailscale未導入時は公式ページからインストールします。
4. WindowsのTailscaleへ本人のアカウントでログインします。
5. 再度設定を実行し、必要なServe許可を行います。
6. 表示された完全URLをスマートフォンで開きます。

https://PC名.tailnet名.ts.net/music-library-search.html

利用者識別
----------
Tailscale Serveが付与する利用者情報でプロフィールを識別します。
ブラウザで利用者IDを選択する方式ではありません。

本人をオーナーへ関連付ける場合
------------------------------
自宅PCの利用者画面でコードを発行し、
本人のTailscale画面からコードを送信します。
自宅PCで表示名・ログイン名・個人状態件数を確認して承認します。

家族
----
家族は同じパスワードを共有せず、個別Tailscaleアカウントを使います。
家族の再生回数とお気に入りは別々に保存されます。

条件
----
・自宅PCの電源が入っている
・PCがスリープしていない
・アプリが起動中
・Tailscaleが接続中
・Serveが有効

安全
----
・Funnelは使用しません。
・ルーターのポートを開けません。
・接続URL、利用者メール、関連付けコードを公開しません。
