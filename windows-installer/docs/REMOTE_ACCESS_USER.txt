Tailscale外部接続ガイド
================================

外部接続にはTailscale Serveを使用します。
Tailscale Funnelとルーターのポート開放は使用しません。

正しいURL形式:
https://PC名.tailnet名.ts.net/music-library-search.html

利用者識別
----------
Tailscale Serveが付与するログイン情報を使い、
接続したTailscaleアカウントごとに利用者を識別します。

家族ごとに次を分けて保存します。

・再生回数
・最終再生日時
・お気に入り
・スキン
・プレイリストと曲順

プレイリスト
------------
各利用者は自分専用のプレイリストを作成できます。
他利用者のプレイリストは表示・編集できません。

スマートフォンのホーム画面へ追加
--------------------------------
1. スマートフォンをTailscaleへ接続
2. 上記のHTTPS URLをSafariまたはChromeで開く
3. 右上の利用者メニューを開く
4. 「スマホのホーム画面に追加」を確認
5. 接続の種類が「Tailscale経由」、通信方式が「HTTPS」であることを確認
6. iPhoneはSafariの共有、Androidはブラウザメニューから追加

注意
----
・PCがスリープまたは電源オフの時は接続できません。
・ホーム画面追加はオフライン再生機能ではありません。
・MP3、DB、アートワーク、認証情報は端末キャッシュへ保存しません。
・市販MP3を第三者へ配布する機能ではありません。
