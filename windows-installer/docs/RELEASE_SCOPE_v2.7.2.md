# v2.7.2 正式リリース対象範囲

## 追加機能

- 6種類の利用者選択式スキン
- 適用前プレビューとキャンセル
- 利用者別スキン保存
- ローカル・Tailscale関連付け済みオーナー間の設定共有
- モノクローム時のアートワーク白黒表示
- スキーマv6と移行前バックアップ

## 実機確認で反映した調整

- ホーム統計カードを各スキンへ完全対応
- 暗色3スキンの利用者表示を高コントラスト化
- キャンディーの可読性調整
- モノクロームとカラースキン間のアートワーク復帰
- スキン適用後の再読み込み保持
- キャンセル時の保存済みスキン復帰

## 継続機能

- ライブラリホーム
- 利用者別再生回数・最終再生日時・お気に入り
- バックアップ・復元
- 新版通知
- Tailscale利用者識別
- オーナー関連付け
- 検索・再生・シーク・シャッフル・リピート

## 変更しないもの

- MP3と元のアートワーク画像
- 既存の曲、利用者、再生回数、お気に入り
- 画面構造と基本操作位置
- 公開済みv2.7.1タグとRelease

## 正式リリース条件

- 全回帰試験に合格
- v2.7.1からの上書きインストールに成功
- 実DBのスキーマv6移行に成功
- 既存データを維持
- スキン保存、再読み込み保持、キャンセル、モノクローム表示に成功
- GitHub Draft Releaseの内容と添付ファイルを確認後、手動で公開
