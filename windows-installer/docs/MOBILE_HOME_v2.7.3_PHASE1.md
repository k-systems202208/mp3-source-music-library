# スマートフォンのホーム画面対応 v2.7.3 工程1

## 目的

TailscaleのHTTPS接続先をスマートフォンのホーム画面へ追加し、専用アイコンからアプリに近い表示で起動できるようにする。

## 実装範囲

- Web App Manifest
- iPhone・iPad、Android向けアプリアイコン
- standalone表示
- 起動中表示
- Service Workerによる最小限の画面資産キャッシュ
- 通信不能時の案内画面
- 利用者画面の「スマホのホーム画面に追加」案内
- 現在のURL表示とコピー
- ローカル接続、Tailscale HTTPS、その他HTTPの表示分離
- safe-areaと44px以上のタップ領域
- 6種類のスキンに応じたテーマ色

## キャッシュしない情報

- API応答
- MP3などの音楽ファイル
- SQLite DB
- バックアップDB
- アートワークキャッシュ
- Tailscaleや利用者の認証情報

## 利用上の注意

外出先でも利用するホーム画面アイコンは、普段使うTailscaleのHTTPS URLをスマートフォンで開いた状態から追加する。自宅PC内のローカルURLから追加すると、外出先ではその接続先を利用できない。

## 工程1の完了条件

- PC上のスマホプレビューで標準、大型、横向き表示が崩れない
- 接続の種類と通信方式が矛盾しない
- PWA資産、MIME、キャッシュ制御、安全な除外対象を自動試験で確認
- main統合後もアプリ表示バージョンは2.7.2のままとし、v2.7.3 RC作成時に統一する
