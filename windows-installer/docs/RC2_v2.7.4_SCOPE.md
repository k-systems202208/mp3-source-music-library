# v2.7.4 RC2 対象範囲

## RC1からの修正

Windows版を再起動した直後、ランチャーが自動で開く`/api/local-auth/exchange?token=...`がChromeで黒い読み込み画面のまま停止し、タブを閉じて「ブラウザで開く」を押し直すと正常に開く現象へ対応する。

## 原因として扱う箇所

ローカルオーナー認証は、ワンタイムトークンをHttpOnly Cookieへ交換した後、本文なしのHTTP 303応答だけでライブラリ画面へ遷移していた。実機では起動直後の最初の自動表示だけ、その応答が読み込み中として残る現象が再現した。

## RC2の変更

- 認証成功応答を小さなHTMLハンドオフページへ変更
- JavaScriptの`window.location.replace`で即時遷移
- JavaScriptが使えない場合はmeta refreshで遷移
- 画面が切り替わらない場合の手動リンクを表示
- `Connection: close`を明示して起動直後の接続を確実に完了
- 認証トークンはHTML本文へ含めない
- Cookieは従来どおりHttpOnly、SameSite=Strict、12時間有効
- 不正・再利用済みトークンは従来どおり401で拒否

## 維持する機能

- 長いファイルパス201曲の登録・再生・シーク
- 8,480曲のライブラリ
- 利用者別お気に入り・再生状態
- スキン、バックアップ・復元、新版通知
- Tailscale接続とスマートフォンホーム画面対応
- DBスキーマv6

## RC2実機合格条件

1. アプリ終了後の再起動で、最初の自動ブラウザ表示がライブラリ画面まで進む。
2. この終了・再起動を3回繰り返して黒い読み込み画面が再発しない。
3. 「ブラウザで開く」でもオーナーとして正常に開く。
4. 8,480曲、お気に入り、履歴、スキンが維持される。
5. 最長364文字の曲をPCとスマートフォンで再生・シークできる。
