# v2.7.4 RC2 起動時オーナー認証修正

## 現象

Windows版を起動した直後、Chromeが `/api/local-auth/exchange?token=...` の黒い画面で読み込み中のまま停止することがありました。タブを閉じ、管理画面の「ブラウザで開く」を押し直すと正常に表示されました。RC1実機試験で再現したため、正式リリース前の修正対象としました。

## 原因と修正

オーナー認証Cookieの発行後に本文なしのHTTP 303だけを返していました。RC2では、次の安全なHTML引き渡しへ変更しました。

- JavaScriptの `window.location.replace` による即時遷移
- JavaScript無効時のmeta refresh
- 手動で開けるライブラリ画面へのリンク
- `Connection: close` による明示的な接続終了
- CSPとX-Frame-Optionsの設定
- ワンタイムトークンをHTML本文へ含めない

## 実機受入結果

2026-08-02、v2.7.4 RC2をWindows 11へ上書きインストールし、アプリ終了・再起動を3回連続で実施しました。3回すべてで認証交換画面に停止せず、ライブラリ画面まで正常に進みました。

長いファイルパス対応の実機結果も維持されています。

- ライブラリ: 8,480曲
- 長いパスから追加: 201曲
- 最長パス: 364文字
- アートワーク: 7,708曲
- 最長パス曲のPC再生: 合格
