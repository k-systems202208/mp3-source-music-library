# v2.7.0 オーナー個人状態統合仕様

この仕様はRC2で実装・検証され、正式版v2.7.0へ採用されました。

## 対象

ローカルオーナーと、オーナー本人のTailscale利用者プロフィールを関連付ける際、Tailscale側に既存の`user_track_state`がある場合です。

## 統合規則

| 項目 | 規則 |
|---|---|
| 再生回数 | オーナー側＋Tailscale側 |
| 最終再生日時 | ISO日時を比較して新しい方 |
| お気に入り | 論理OR |
| 評価 | 片方がNULLなら設定済み側。同値なら維持。異値なら中止 |
| created_at | 両側にある場合は既存オーナー行を維持 |
| updated_at | 統合実行日時 |

## 安全境界

1. 候補利用者とTailscale subjectを再照合
2. 候補が有効であることを確認
3. 識別情報件数を確認
4. 評価競合・日時解釈を変更前に検査
5. 専用バックアップを作成
6. 個人状態を統合
7. Tailscale識別情報をオーナーへ移動
8. 空になった候補プロフィールを削除
9. `PRAGMA foreign_key_check`
10. 失敗時は全体をロールバック

バックアップ:

```text
Backups/library-pre-owner-link-YYYYMMDD-HHMMSS.db
```

## 実機結果

2026-08-01、本人Tailscaleプロフィールの個人状態3曲・再生3回をローカルオーナーへ統合し、PCとスマートフォン間の状態共有・再起動後保持を確認しました。
