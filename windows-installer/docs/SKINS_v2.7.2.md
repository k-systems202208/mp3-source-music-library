# v2.7.2 スキン機能

## 目的

画面構造、機能、操作位置を共通のまま維持し、色、背景、枠線、影、発光、装飾を利用者ごとに切り替えます。

## 搭載スキン

| ID | 表示名 | 特徴 |
|---|---|---|
| `library` | ライブラリー | 紙とカード目録を基調とした標準デザイン |
| `midnight` | ミッドナイト | 落ち着いた濃紺のダークデザイン |
| `neon` | ネオン | 黒地にシアンとマゼンタの発光 |
| `cyberpunk` | サイバーパンク | 黄色とマゼンタの端末風デザイン |
| `candy` | キャンディー | ビビッドでカラフルな明るいデザイン |
| `monochrome` | モノクローム | 白・黒・グレー。アートワークも画面上で白黒表示 |

一覧にない値や任意CSSは保存しません。

## UI

1. 利用者メニューから「スキンを変更」を開く
2. カードを選択して画面全体へ一時反映
3. 「適用する」でDBへ保存
4. キャンセルまたは画面を閉じると保存済みスキンへ戻る

保存に失敗した場合も、変更前の表示へ戻します。

## 保存モデル

スキーマv6の`user_preferences`へ次を保存します。

- `user_id`
- `skin_id`
- `updated_at`

スキンは利用者単位です。ローカルオーナーと関連付け済みTailscaleオーナーは同じ利用者IDを参照します。未識別接続は`library`を使用し、保存APIを利用できません。

## API

### 現在利用者

`GET /api/current-user`

レスポンスへ`skinId`を含めます。未識別時は`library`です。

### スキン保存

`PUT /api/me/skin`

```json
{
  "skinId": "cyberpunk"
}
```

利用者IDはクライアントから受け取りません。サーバーが接続元から現在利用者を解決します。

## 表示方式

HTMLルート要素の`data-skin`を切り替え、CSS変数で見た目を変更します。スキンごとに別HTMLを持ちません。

モノクロームではCSSフィルターを使って表示時だけアートワークを白黒化します。元の画像とキャッシュは変更しません。

## 読みやすさ

- 暗色スキンでは利用者名と本文を高コントラスト化
- 選択状態を色だけに依存させない
- キーボードフォーカスを表示
- 統計カード、通知、入力欄、ボタンを同じスキン変数で統一
- PC・タブレット・スマートフォンでページ全体の横スクロールを発生させない

## バックアップ

`user_preferences`は`library.db`に保存するため、通常のバックアップ・復元対象です。v5以前のDBを復元した場合は自動移行し、スキン未設定の利用者には`library`を適用します。
