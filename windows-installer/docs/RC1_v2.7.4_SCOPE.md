# v2.7.4 RC1 対象範囲

## 目的

Windowsの長いファイルパスにある実際の201曲を本番DBへ登録し、PC・Tailscale接続先から再生とシークができることを実機確認する。

## 対象

- ローカルドライブの長いパス形式
- UNCネットワークパスの長いパス形式
- MP3走査、タグ、音声情報、アートワーク、内容署名
- SQLiteへの通常相対パス保存
- HTTP Range配信とシーク
- 8,279曲から8,480曲への本番スキャン
- 既存曲IDと利用者状態の維持

## 対象外

- ファイル名・フォルダー名の自動短縮
- MP3タグや音源ファイルの書換え
- DBスキーマ変更
- 長いパス機能をOS全体へ強制設定する処理

## 安全条件

既存DBを上書き更新する通常スキャンの前に日次バックアップが存在することを確認する。利用者、お気に入り、再生状態、スキン、Tailscale関連付けを維持し、既存8,279曲のIDを変えない。
