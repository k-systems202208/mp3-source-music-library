# v2.7.3 正式リリース対象範囲

## 追加機能

- iPhone・iPad・Android向けPWAアイコン
- Web App Manifestとstandalone起動
- 起動中画面と通信不能時画面
- Service Workerによる最小限の画面資産キャッシュ
- 利用者メニューのホーム画面追加案内
- 現在の接続先URL表示・コピー
- ローカル接続、Tailscale HTTPS、通常HTTPの表示判定
- safe-area、タップ領域、縦横レイアウト
- 6種類のスキンに応じたテーマ色

## 実機確認で確認した内容

- v2.7.2からの上書きインストール
- iPhoneのホーム画面に専用アイコンを追加
- アイコンからアドレスバーのないstandalone画面で起動
- Tailscale経由、HTTPS、ホーム画面起動中の表示
- 利用者、お気に入り、再生履歴、スキンの維持
- スマートフォンのライブラリホーム表示

## 継続機能

- ライブラリホーム
- 利用者別再生状態・お気に入り
- 6種類のスキン
- バックアップ・復元
- 新版通知
- Tailscale利用者識別とオーナー関連付け
- 検索・再生・シーク・シャッフル・リピート

## 変更しないもの

- DBスキーマv6
- MP3と元のアートワーク
- 既存の利用者状態、スキン、バックアップ
- 公開済みv2.7.2タグとRelease

## 対象外

- MP3のオフライン保存
- App Store・Google Play配布
- プッシュ通知
- バックグラウンド再生保証

## 正式リリース条件

- 全回帰試験に合格
- v2.7.2からの上書きインストールに成功
- iPhone実機でホーム画面追加とstandalone起動に成功
- Tailscale HTTPS接続と利用者状態維持を確認
- GitHub Draft Releaseの内容と添付ファイルを確認後、手動で公開
