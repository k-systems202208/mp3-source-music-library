# v2.7.5 プレイリスト本番表示・スマートフォン修正

## RC1で確認した現象

iPhoneのホーム画面アイコンからv2.7.5 RC1を開いた際、本番DBで動作しているにもかかわらず、工程1プレビュー用の次の案内が表示されました。

```text
v2.7.5 機能プレビュー
複製DBでプレイリスト機能を確認しています
```

また、5個の画面タブのうち「アーティスト」と「プレイリスト」が2行に折り返されました。

## RC2の修正

- 本番HTMLから工程1用プレビュー案内を完全に除去
- 保存済みURLに`playlistPreview=1`が残っていても起動時に削除
- プレビューURLによるプレイリスト画面の強制表示を廃止
- Service Workerのキャッシュ名を更新
- RC1の古い画面資産を新しい資産へ置換
- スマートフォンの画面タブを改行禁止に変更
- 日本語タブが1行に収まるよう余白を調整
- 専用の本番画面・PWA回帰試験を追加

## 実機確認

iPhoneのホーム画面アイコンからRC2を起動し、次を確認しました。

- プレビュー案内が表示されない
- 5個の画面タブがすべて1行
- 8,480曲、アートワーク7,708曲
- 利用者「オーナー」
- サイバーパンクスキン
- RC1で作成した「RC1確認」プレイリスト
- プレイリスト内の3曲と曲順
- 個別再生、上下移動、削除操作のUI
- ページ全体の横方向の崩れなし
