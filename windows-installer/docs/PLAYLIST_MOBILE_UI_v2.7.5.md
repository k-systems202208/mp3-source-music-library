# v2.7.5 プレイリスト・モバイル本番表示

## RC1で確認した問題

- 実運用版に工程1用「機能プレビュー／複製DB」案内が残った
- スマートフォンで「アーティスト」「プレイリスト」が折り返した
- 古いService Workerキャッシュや`playlistPreview`付きURLが残る可能性

## RC2の修正

- 本番HTMLからプレビュー案内を除去
- 起動時に`playlistPreview`をURLから除去
- プレビュー用パラメーターで画面を強制しない
- Service Workerキャッシュ名を更新
- 5タブを`white-space: nowrap`で1行表示
- モバイル時の余白と文字サイズを調整
- 専用回帰試験を追加

## 実機確認

- iPhoneホーム画面アイコンから起動
- 5タブが1行
- プレビュー案内なし
- 8,480曲、7,708アートワーク
- 利用者とサイバーパンクスキン維持
- プレイリスト1件・3曲維持
- 曲順・再生・編集ボタン表示
- ページ全体の横崩れなし

## キャッシュ境界

Service Workerは画面シェルだけを対象とし、プレイリストAPIや個人データをキャッシュしません。プレイリストの正本はサーバーの`library.db`です。
