# v2.7.6 正式リリース範囲

公開日: 2026-08-04

## 変更

- 曲名・アーティスト名の表示変更をオーナー限定化
- UIとAPIの両方で権限を強制
- 「訂正済」表示・絞り込みを削除
- プレーヤーのアーティスト名・アルバム名をリンク化
- 安全なコピーDBを使うソース確認用バッチを追加

## 維持

- DBスキーマ7
- 既存の表示変更値
- 曲ID、利用者、識別、再生状態、お気に入り、スキン、プレイリスト
- MP3、タグ、ファイル名、フォルダー構成
- Tailscale Serveによる外部接続

## 受入

- ユーザーによる画面確認済み
- 全34ソース回帰試験（合格）
- PyInstaller EXEスモーク試験（合格）
- Inno Setupコンパイル（合格）
- Release Assets 6ファイルとSHA-256検証（合格）

## 対象外

- アルバム名の編集
- MP3タグへの書き戻し
- プレイリスト共有・M3U入出力
- オフライン音楽保存
