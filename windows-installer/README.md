# 自宅音楽ライブラリ v2.7.2

手元のMP3を音源の正本として、タグ、アートワーク、検索情報、利用者別の再生状態をSQLiteで管理し、Windows PC・スマートフォン・タブレットのブラウザから検索・再生する個人／家庭向け音楽ライブラリです。

> 製品バージョン：2.7.2
> DBスキーマ：6
> 対応OS：Windows 10／11 64bit
> 更新日：2026-08-02

## v2.7.2の主な内容

v2.7.2では、画面構造と操作方法を維持したまま、利用者ごとに見た目を変更できるスキン機能を追加しました。

- ライブラリー
- ミッドナイト
- ネオン
- サイバーパンク
- キャンディー
- モノクローム

スキンカードを選ぶとその場でプレビューし、「適用する」を押した場合だけ保存します。キャンセルすると保存済みの表示へ戻ります。

モノクロームではアートワークも白黒表示になりますが、元画像は変更しません。

## インストールまたは更新

1. 自宅音楽ライブラリを終了します。
2. `MusicLibrary-Setup-2.7.2-x64.exe`を実行します。
3. v2.7.1以前が入っていても、アンインストールせず上書きします。
4. スタートメニューから「自宅音楽ライブラリ」を起動します。

利用者データとMP3はインストール先とは別に保持されます。

```text
%LOCALAPPDATA%\MusicLibrary
```

## 主な機能

- MP3・ID3タグ・アートワークの読込み
- ライブラリホーム
- 曲名・アーティスト・アルバム検索
- ブラウザ再生、シーク、シャッフル、リピート
- 利用者別の再生回数・最終再生日時・お気に入り
- 利用者別スキン
- バックアップ・復元
- GitHub Releaseを利用した新版通知
- Tailscale Serve経由の外部利用
- ローカルオーナーと本人Tailscaleプロフィールの関連付け

## スキン

| スキン | 特徴 |
|---|---|
| ライブラリー | 紙とカード目録を基調とした標準デザイン |
| ミッドナイト | 落ち着いた濃紺のダークデザイン |
| ネオン | 黒地にシアンとマゼンタの発光 |
| サイバーパンク | 黄色とマゼンタの端末風デザイン |
| キャンディー | ビビッドでカラフルな明るいデザイン |
| モノクローム | 白・黒・グレー。アートワークも表示時だけ白黒化 |

スキンは認証済み利用者ごとに保存します。ローカルオーナーと関連付け済みTailscaleオーナーは同じ設定を共有します。未識別利用者は標準のライブラリーを使用します。

## スキーマv6

利用者別スキンを保存するため、`user_preferences`テーブルを追加しました。v5以前のDBは初回起動時に自動移行します。

移行前に次のバックアップを作成します。

```text
%LOCALAPPDATA%\MusicLibrary\Backups\library-pre-v2.7.2-YYYYMMDD-HHMMSS.db
```

バックアップ作成または検証に失敗した場合は、移行を開始しません。

## ビルド

短いパスへソースを配置し、`00_build_installer.bat`を実行します。

```text
C:\ML272Build
```

成功すると`release`フォルダーに次を作成します。

- `MusicLibrary-Setup-2.7.2-x64.exe`
- `MusicLibrary-Setup-2.7.2-x64_SHA256.txt`
- ビルドログ
- ビルド報告

## 制限

- 対象音源はMP3です
- 自動ダウンロード・自動更新は行いません
- 公開インターネットへ直接ポートを開ける運用は対象外です
- 自宅PCが停止またはスリープ中は外部接続できません
- Windowsサービスとしての常駐には対応していません
