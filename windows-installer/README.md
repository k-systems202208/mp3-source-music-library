# 自宅音楽ライブラリ v2.7.4

手元のMP3を音源の正本として、タグ、アートワーク、検索情報、利用者別の再生状態をSQLiteで管理し、Windows PC・スマートフォン・タブレットのブラウザから検索・再生する個人／家庭向け音楽ライブラリです。

> 製品バージョン：2.7.4
> DBスキーマ：6
> 対応OS：Windows 10／11 64bit
> 更新日：2026-08-02

## v2.7.4の主な内容

Windowsの従来のパス長制限により読み込めなかった、深いフォルダーや長いファイル名のMP3へ対応しました。

- 260文字以上のローカルファイルパスに対応
- UNCネットワークパスの長いパス形式に対応
- 再帰走査、ファイル情報、ID3タグ、Mutagen音声情報を長いパス対応
- 埋め込み・外部アートワーク取得を長いパス対応
- 移動検出用の内容署名を長いパス対応
- MP3のHTTP配信とRange指定による途中位置再生を長いパス対応
- SQLiteには従来どおり通常の相対パスを保存
- 起動直後のローカルオーナー認証画面が停止する現象を修正

## 実機確認結果

- 音楽フォルダー内MP3：8,480曲
- 従来の登録曲：8,279曲
- 長いパスにより未登録だった曲：201曲
- v2.7.4実運用DBへの登録：8,480曲
- 長いパス201曲の登録：201曲
- スキャンエラー：0件
- アートワーク：7,708曲
- 最長パス：364文字
- 最長364文字の曲をPCブラウザで再生・シーク
- 既存曲ID、利用者、お気に入り、再生状態、スキン設定を維持
- RC2でアプリ終了・再起動を3回繰り返し、起動認証が毎回正常に完了

## インストールまたは更新

1. 自宅音楽ライブラリを終了します。
2. `MusicLibrary-Setup-2.7.4-x64.exe`を実行します。
3. v2.7.3以前が入っていても、アンインストールせず上書きします。
4. スタートメニューから「自宅音楽ライブラリ」を起動します。

利用者データとMP3はインストール先とは別に保持されます。

```text
%LOCALAPPDATA%\MusicLibrary
```

## 長いファイルパスの扱い

Windows内部でファイルを開くときだけ`\\?\`形式を使用します。DBとブラウザには従来どおり通常の相対パスを渡します。

変更しないもの：

- MP3ファイル
- ID3タグ
- ファイル名・フォルダー名
- 元のアートワーク
- DBスキーマv6

## 主な機能

- MP3・ID3タグ・アートワークの読込み
- Windowsの長いファイルパス対応
- ライブラリホーム
- 曲名・アーティスト・アルバム検索
- ブラウザ再生、シーク、シャッフル、リピート
- 利用者別の再生回数・最終再生日時・お気に入り
- 6種類の利用者別スキン
- バックアップ・復元
- GitHub Releaseを利用した新版通知
- Tailscale Serve経由の外部利用
- ローカルオーナーと本人Tailscaleプロフィールの関連付け
- スマートフォンのホーム画面追加とPWA起動

## 制限

- 対象音源はMP3です
- スマートフォンへの音楽オフライン保存は行いません
- App Store・Google Playでは配布しません
- 公開インターネットへ直接ポートを開ける運用は対象外です
- 自宅PCが停止またはスリープ中は外部接続できません
- Windowsサービスとしての常駐には対応していません
