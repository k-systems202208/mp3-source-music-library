# 自宅音楽ライブラリ v2.7.5

手元のMP3を音源の正本として、タグ、アートワーク、検索情報、利用者別の再生状態とプレイリストをSQLiteで管理し、Windows PC・スマートフォン・タブレットのブラウザから検索・再生する個人／家庭向け音楽ライブラリです。

> 製品バージョン：2.7.5
> DBスキーマ：7
> 対応OS：Windows 10／11 64bit
> 更新日：2026-08-03

## v2.7.5の主な内容

利用者ごとに独立したプレイリストを作成し、好きな曲を任意の順序で続けて再生できるようになりました。

- プレイリストの作成・名称変更・削除
- 曲一覧の「＋」から任意のプレイリストへ追加
- 同じ曲の重複追加を防止
- プレイリスト内の曲順変更
- プレイリストから曲を外す操作
- プレイリスト全曲再生
- 前へ・次へ・シャッフル・リピートとの連携
- オーナーとTailscale利用者ごとにプレイリストを分離
- PC・スマートフォン向けレスポンシブ表示
- スマートフォンの5個の画面タブを1行表示に調整
- DBスキーマを6から7へ更新
- 更新前に`library-pre-v2.7.5-*.db`を自動作成

## 実機確認結果

- v2.7.4から上書きインストール
- ライブラリ収録曲：8,480曲
- アートワーク：7,708曲
- お気に入り、再生回数、再生履歴、スキンを維持
- スマートフォンのホーム画面アイコンから起動
- 実運用DBに「RC1確認」プレイリストと3曲を保存
- RC2上書き後もプレイリスト、曲順、利用者、スキンを維持
- 本番画面から工程1用の「機能プレビュー／複製DB」案内を除去
- 「アーティスト」「プレイリスト」をスマートフォンで1行表示
- ページ全体の横方向の崩れなし

利用者間のプレイリスト分離、重複防止、作成・名称変更・削除、並べ替え、全曲再生、バックアップ・復元は自動回帰試験に合格しています。

## インストールまたは更新

1. 自宅音楽ライブラリを終了します。
2. `MusicLibrary-Setup-2.7.5-x64.exe`を実行します。
3. v2.7.4以前が入っていても、アンインストールせず上書きします。
4. スタートメニューから「自宅音楽ライブラリ」を起動します。

初回起動時にDBスキーマを7へ更新し、更新前のDBを次へ自動保存します。

```text
%LOCALAPPDATA%\MusicLibrary\Backups\library-pre-v2.7.5-*.db
```

利用者データとMP3はインストール先とは別に保持されます。

```text
%LOCALAPPDATA%\MusicLibrary
```

## プレイリストの使い方

1. 上部の「プレイリスト」を開きます。
2. 「新しいプレイリスト」で名前を付けます。
3. 曲名・アーティスト・アルバム画面の曲カードにある「＋」を押します。
4. 追加先のプレイリストを選びます。
5. プレイリスト画面で曲順変更、個別再生、全曲再生、曲の削除を行います。

プレイリストから曲を外したり、プレイリスト自体を削除しても、MP3ファイルと通常の曲一覧は削除されません。

## 利用者ごとの分離

認証済み利用者ごとに、次を独立して保存します。

- 再生回数
- 最終再生日時
- お気に入り
- スキン
- プレイリストと曲順

他の利用者のプレイリストIDを指定しても、その内容は返しません。

- ローカルオーナーと本人Tailscaleプロフィールの関連付け
- スマートフォンのホーム画面追加とPWA起動

## GitHubへ公開しないもの

- MP3・音源ファイル
- `library.db`、WAL、SHM
- `.artwork-cache`
- `Backups`、`Exports`、`Logs`
- `config.json`、`remote-url.txt`
- 実際のTailscale利用者情報
- トークン、秘密鍵、Cookie、関連付けコード

## 制限

- 対象音源はMP3です
- プレイリストの共有・共同編集には対応していません
- M3Uなど外部プレイリスト形式の入出力には対応していません
- スマートフォンへの音楽オフライン保存は行いません
- App Store・Google Playでは配布しません
- 公開インターネットへ直接ポートを開ける運用は対象外です
- 自宅PCが停止またはスリープ中は外部接続できません
- Windowsサービスとしての常駐には対応していません
