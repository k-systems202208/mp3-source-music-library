# 自宅音楽ライブラリ v2.7.0 RC2 インストーラービルド一式

RC1の実機確認中、オーナー本人のTailscaleプロフィールに
すでに再生回数・お気に入りが保存されていることを確認しました。

RC2では、その個人データを失わずにローカルオーナーへ統合してから、
Tailscale識別情報をオーナーへ関連付けます。

## RC2で追加した安全な統合

```text
再生回数       ：オーナー側とTailscale側を合算
最終再生日時   ：新しい方を採用
お気に入り     ：どちらかが★なら★
評価           ：片方だけ設定なら引き継ぐ
                 両方が同じなら維持
                 異なる場合は関連付けを中止
```

関連付け前には、従来どおり専用バックアップを作成します。
統合、識別情報の移動、重複プロフィール削除は一つのトランザクションで行います。

## 今回の段階

まずWindows上でRC2インストーラーを作成します。

```text
release\MusicLibrary-Setup-2.7.0-x64.exe
```

作成後も、ビルド報告を確認するまではSetup.exeを実行しません。

## ビルド

```text
00_build_installer.bat
```

成功すると、全回帰テスト、PyInstallerによるEXE作成、
空ライブラリでの起動検査、Inno Setupによるインストーラー作成、
SHA-256生成まで自動実行します。

ビルド報告：

```text
release\BUILD_REPORT_v2.7.0_RC2.txt
```

## 更新

RC1とRC2はどちらも製品バージョン2.7.0です。
RC2確認時はRC1をアンインストールせず、同じ場所へ上書きします。

利用者データは次にあり、インストール先とは別です。

```text
%LOCALAPPDATA%\MusicLibrary
```
