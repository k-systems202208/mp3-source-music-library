# 自宅音楽ライブラリ v2.7.5

公開日: 2026-08-03

## 利用者別プレイリスト

- プレイリストの作成・名称変更・削除
- 曲カードから追加
- 同じ曲の重複追加防止
- 曲順を上下へ変更
- プレイリストから曲を外す
- 個別再生・全曲再生
- 前へ・次へ・シャッフル・リピートとの連携
- オーナーとTailscale利用者ごとの所有権分離

プレイリストを削除しても、MP3ファイルと通常の曲一覧は削除しません。

## DBスキーマ7

- `playlists`
- `playlist_tracks`
- 利用者内のプレイリスト名一意制約
- 同一曲の重複防止
- 曲順の一意制約
- schema 6から7への移行前バックアップ

```text
%LOCALAPPDATA%\MusicLibrary\Backups\library-pre-v2.7.5-*.db
```

スキーマ7のバックアップ・復元にも対応します。

## スマートフォン表示

- 5個の画面タブを1行表示
- 本番画面から機能プレビュー案内を除去
- 古い`playlistPreview`パラメーターを除去
- Service Workerキャッシュを更新
- RC1で作成したプレイリストと曲順をRC2上書き後も維持

## 実機確認

- v2.7.4から上書きインストール
- 8,480曲
- アートワーク7,708曲
- お気に入り、再生履歴、再生回数、利用者、スキンを維持
- 実運用DBでプレイリスト1件・3曲
- iPhoneのホーム画面アイコンから表示
- ページ全体の横崩れなし
- v2.7.5 RC2の全ソース回帰試験、EXEスモーク試験、Inno Setupコンパイルに合格

数値は受入環境の実績であり、製品の固定上限ではありません。

## 継続対応

- Windows長パス
- 起動時オーナー認証
- PWA
- 利用者別スキン
- ライブラリホーム
- バックアップ・復元
- 新版通知
- 利用者別履歴・お気に入り
- Tailscale Serve

## 更新方法

起動中のアプリを終了し、`MusicLibrary-Setup-2.7.5-x64.exe`を旧版へ上書きします。アンインストールは不要です。

## 対象外

- プレイリスト共有・共同編集
- M3U等の入出力
- 自動選曲
- MP3オフライン保存
- App Store／Google Play配布
