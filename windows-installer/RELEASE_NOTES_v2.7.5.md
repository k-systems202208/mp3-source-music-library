# 自宅音楽ライブラリ v2.7.5

v2.7.5では、利用者ごとに独立したプレイリストを作成し、好きな曲を任意の順序で続けて再生できるようになりました。

## 利用者別プレイリスト

- プレイリストの作成・名称変更・削除
- 曲一覧から任意のプレイリストへ曲を追加
- 同じ曲の二重登録を防止
- プレイリスト内の曲順変更
- プレイリストから曲を外す操作
- プレイリスト全曲再生
- 前へ・次へ・シャッフル・1曲／全曲リピートとの連携
- PCとスマートフォン幅のレスポンシブ表示

プレイリストを削除してもMP3ファイルや通常の曲レコードは削除されません。

## 利用者ごとの分離

プレイリストは現在の認証利用者に紐づきます。オーナー、家族などのTailscale利用者は、それぞれ自分のプレイリストだけを表示・編集できます。

APIでも現在の利用者を基準に所有権を確認し、他利用者のプレイリストIDを指定しても内容を返しません。

## データベース更新

DBスキーマを6から7へ更新し、次のテーブルを追加します。

```text
playlists
playlist_tracks
```

更新前には`Backups`フォルダーへ`library-pre-v2.7.5-*.db`を自動作成します。

MP3ファイル、タグ、ファイル名、フォルダー名は変更しません。既存の8,480曲、利用者、お気に入り、再生履歴、再生回数、スキン、Tailscale関連付けを維持します。

## RC2での本番表示修正

RC1のスマートフォン実機確認で、本番DBを使用しているにもかかわらず工程1用の「v2.7.5 機能プレビュー／複製DB」案内が表示され、5個の画面タブのうち「アーティスト」「プレイリスト」が2行に折り返されることを確認しました。

RC2では次を修正しました。

- 本番HTMLから工程1用プレビュー案内を完全に除去
- 保存済みURLに`playlistPreview=1`が残っていても起動時に削除
- プレビュー用URLによる画面強制切替を廃止
- Service Workerのキャッシュ名を更新し、RC1の画面資産を破棄
- スマートフォンの5個の画面タブを改行禁止に変更
- 日本語タブが1行に収まるようモバイル時の余白を調整

iPhoneのホーム画面アイコンから起動し、プレビュー案内が消え、すべてのタブが1行表示され、RC1で作成したプレイリストと3曲が維持されることを実機確認しました。

## 自動・実機確認

- RC2ビルドの34項目の機能・回帰試験に合格
- バンドル済みEXEの起動試験に合格
- Inno Setupコンパイルに合格
- v2.7.4から上書きインストール
- 8,480曲、アートワーク7,708曲を維持
- お気に入り、再生回数、再生履歴、スキンを維持
- スマートフォンでプレイリスト1件・3曲を表示
- RC2上書き後もプレイリストと曲順を維持
- 本番画面のプレビュー案内を除去
- スマートフォンの5タブを1行表示
- ページ全体の横方向の崩れなし

利用者間の分離、重複防止、名称変更、削除、並べ替え、全曲再生、バックアップ・復元は自動回帰試験で確認しています。

## 更新方法

自宅音楽ライブラリを終了し、`MusicLibrary-Setup-2.7.5-x64.exe`を実行します。v2.7.4をアンインストールする必要はありません。

曲、利用者、お気に入り、再生履歴、スキン、バックアップ、Tailscale設定、スマートフォンのホーム画面利用は維持されます。
