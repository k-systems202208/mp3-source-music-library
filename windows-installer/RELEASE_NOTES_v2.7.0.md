# 自宅音楽ライブラリ v2.7.0

v2.7.0では、家族で同じ音楽ライブラリを利用しても、
再生回数とお気に入りを利用者ごとに分けて保存できるようになりました。

## 主な追加機能

- ローカルPCの利用者をオーナーとして安全に識別
- Tailscale Serve経由の利用者をアカウント単位で識別
- ローカルオーナーと本人のTailscaleアカウントを確認付きで関連付け
- 現在の利用者を画面右上へ表示
- オーナー向けの最小限の利用者管理
- 利用者ごとの再生回数
- 利用者ごとの最終再生日時
- 利用者ごとのお気に入り
- 「★ お気に入りのみ」による絞り込み

## v2.6.3からのデータ移行

初回起動時に、既存の共通データをオーナーへ引き継ぎます。

- 再生回数
- 最終再生日時
- お気に入り
- 評価

移行直前には、次へ専用バックアップを作成します。

```text
%LOCALAPPDATA%\MusicLibrary\Backups
└─ library-pre-v2.7.0-YYYYMMDD-HHMMSS.db
```

バックアップの作成や検査に失敗した場合、移行は開始しません。
移行途中で失敗した場合は、変更をロールバックします。

## 利用者の識別

ローカルPCから管理画面経由で開いた場合は、オーナーとして識別します。

Tailscale Serve経由では、Tailscaleが付与する利用者情報を使います。
ブラウザから任意の利用者IDを指定する方式ではありません。

未識別の接続でも検索と再生はできますが、
再生回数とお気に入りは保存されません。

## オーナーとTailscaleの関連付け

関連付けは自動では行いません。

1. ローカルオーナーが一時コードを発行
2. Tailscale側の本人がコードを入力
3. ローカル側で表示名とログイン名を確認
4. オーナーが明示的に承認

家族のアカウントが誤ってオーナーになることを防ぎます。

## オーナー本人に既存の個人データがある場合

Tailscale側で先に再生やお気に入りを使用していても、
そのデータを失わずにローカルオーナーへ統合できます。

- 再生回数は合算
- 最終再生日時は新しい方を採用
- お気に入りはどちらかが登録済みなら維持
- 評価は競合がなければ引き継ぎ
- 両側で異なる評価が設定されている曲がある場合は、推測せず関連付けを中止

統合前には専用バックアップを作成し、処理全体を一つのトランザクションで行います。

## 更新方法

v2.6.3をアンインストールせず、
`MusicLibrary-Setup-2.7.0-x64.exe`を上書きインストールします。

インストール前に自宅音楽ライブラリを停止してください。

次の利用者データは維持されます。

- 音楽フォルダ設定
- library.db
- 表記補正
- アートワークキャッシュ
- バックアップ
- ログ
- 外部接続URL

## 既知の仕様

- 利用者の完全削除は行わず、利用停止・再開で管理します。
- オーナーは利用停止にできません。
- Tailscale経由のオーナーは利用者一覧を閲覧できますが、
  利用停止・再開などの変更操作はローカルPCから行います。
- コード署名していないため、Windows SmartScreenに
  「不明な発行元」と表示される場合があります。
