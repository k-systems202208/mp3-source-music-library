# 自宅音楽ライブラリ v2.7.1

v2.7.1では、曲を探し始めるまでの操作を短くし、日常的なデータ保護と新版確認を画面から行えるようにしました。

## ライブラリホーム

起動直後にホーム画面を表示します。

- 最近再生した曲
- お気に入り
- よく聴く曲
- 最近追加した曲
- すべての曲・アーティスト・アルバム・お気に入りへのショートカット
- 収録曲数、お気に入り数、利用者の再生回数、アートワーク数

最近再生した曲、お気に入り、よく聴く曲は、現在の利用者ごとの状態を表示します。最近追加した曲はライブラリ共通です。

## バックアップ・復元画面

自宅PCのローカルオーナー画面から、データベースの保護状態を確認できます。

- 手動バックアップの作成
- バックアップ一覧と整合性検証
- 収録曲数・スキーマ・作成種別の表示
- 復元対象の二段階確認
- 復元予約の取消
- 次回起動時の安全な復元
- 復元直前の自動バックアップ

起動中のデータベースを直接上書きせず、次回起動時にデータベースを開く前に復元します。

## 新版通知

自宅PCのローカルオーナーだけに、GitHubの公開済みRelease情報を表示します。プレリリース設定のReleaseも確認対象です。

- 1日1回の自動確認
- 「今すぐ確認」による手動再確認
- 確認完了時刻の表示
- Releaseページへのリンク
- 「後で」による一時的な非表示
- 通信失敗時の前回結果利用

自動ダウンロードや自動インストールは行いません。新版確認に失敗しても、起動・検索・再生には影響しません。

## 継続される機能

v2.7.0で追加した次の機能は、そのまま利用できます。

- 利用者別の再生回数・最終再生日時・お気に入り
- ローカルオーナーとTailscale本人の安全な関連付け
- 既存状態を失わないオーナーへの統合
- お気に入りだけの絞り込み

## 更新方法

自宅音楽ライブラリを終了し、`MusicLibrary-Setup-2.7.1-x64.exe`を実行します。v2.7.0をアンインストールする必要はありません。

利用者データとMP3は、アプリのインストール先とは別に保持されます。
