# 用語集

| 用語 | 意味 |
|---|---|
| 音源の正本 | 曲の存在と音声内容を決める実MP3 |
| 管理情報の正本 | 検索情報・補正・利用者状態を保存する`library.db` |
| schema 5 | v2.7.0のDB形式。利用者関連3テーブルを含む |
| ローカルオーナー | Windows管理画面から一時トークン交換で識別されたオーナー |
| Tailscale利用者 | Tailscale Serveの利用者ヘッダーで識別されたプロフィール |
| subject | provider内で安定した識別子。Tailscaleでは正規化ログイン名 |
| provider | 識別元。`local_owner`または`tailscale` |
| 匿名 | 利用者を確認できない状態。検索・再生のみ |
| 個人状態 | 利用者ごとの再生回数、最終再生日時、お気に入り、評価 |
| `user_track_state` | 利用者×曲の個人状態テーブル |
| オーナー関連付け | ローカルオーナーへ本人Tailscale識別を結び付ける確認処理 |
| claim | Tailscale利用者が一時コードを送信して候補になる操作 |
| 統合プレビュー | 承認前に個人状態件数・競合を確認する処理 |
| 評価競合 | 同じ曲に異なる非NULL評価が両プロフィールへある状態 |
| Tailscale Serve | tailnet内HTTPSをlocalhostサービスへ中継する機能 |
| Funnel | インターネット全体へ公開する機能。本アプリでは使用しない |
| Byte Range | MP3の一部分だけを要求・返却するHTTP機能 |
| 内容署名 | MP3移動・改名の候補判定に使うファイル内容の軽量署名 |
| `is_available` | 現在MP3が存在するかを示す論理フラグ |
| 表記補正 | 元タグを変更せず、画面用の曲名・アーティスト名をDBへ保存する機能 |
| 疎な状態 | 値がある利用者×曲だけ`user_track_state`へ保存する方式 |
| 移行前バックアップ | schema変更直前に作る`library-pre-v2.7.0-*` |
| 関連付け前バックアップ | オーナー統合直前に作る`library-pre-owner-link-*` |
| 回帰試験 | 既存機能が新変更で壊れていないことを確認する試験 |
| スモーク試験 | バンドル済み実行ファイルが最低限起動できることを確認する試験 |
