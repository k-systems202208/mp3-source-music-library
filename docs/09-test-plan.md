# 試験計画

## 目的

v2.7.5のインストール、DBスキーマ7、既存機能、プレイリスト、長いパス、PWA、利用者分離が安全に動作することを確認します。

## 自動試験群

- Windows BAT整合性
- ビルド健全性
- ブラウザ切断
- リモート接続解析・entry path
- ランチャー安定性
- schema 5→6→7移行
- ローカルオーナー認証
- 起動認証の繰り返し引き渡し
- Tailscale利用者識別
- オーナー関連付けと状態統合
- 利用者管理
- 利用者別再生状態・お気に入り
- ライブラリホーム
- バックアップ・復元
- プレイリストDB・API・UI・所有権
- 本番プレイリスト表示とスマートフォンタブ
- 新版通知
- スキンとschema 7
- PWA資産、キャッシュ安全性、モバイル表示、配信
- Windows長パスの走査・タグ・画像・Range再生
- 読み取り専用長パスプローブ
- 複製DBフルスキャン
- RC整合性
- PyInstaller EXEスモーク
- Inno Setupコンパイル

v2.7.5 RC2では、これらのグループ化された回帰・機能確認に合格しています。

## DB移行受入

- v2.7.4／schema 6から上書き
- 移行前バックアップ作成
- schema 7
- 既存曲ID維持
- 利用者、識別、状態、スキン維持
- 8,480曲維持
- 外部キー・quick check合格

## プレイリスト受入

- 作成
- 同名競合
- 3曲追加
- 同一曲の重複防止
- 曲順上下
- 個別再生
- 全曲再生
- 前後、シャッフル、リピート
- 名称変更
- 曲を外してもMP3・通常一覧を維持
- プレイリスト削除
- アプリ再起動後の永続化
- RC2上書き後の永続化
- 他利用者から不可視・更新不可

## スマートフォン受入

- Tailscale HTTPS
- ホーム画面アイコンからstandalone起動
- 利用者・スキン維持
- 5タブが1行
- プレビュー案内なし
- プレイリスト表示・再生
- 横方向のページ崩れなし
- safe area
- オフライン時に音楽が再生できないことを仕様として確認

## 長いパス受入

確認環境:

- 長いパス201曲
- 最長364文字
- 読み取り・シーク201／201
- 複製DBで8,480／8,480登録
- エラー0
- 実ファイル3曲の先頭・中間Range配信

## 起動認証受入

- 上書きインストール後
- アプリ完全終了→起動を3回
- 3回とも認証交換URLで停止せずUIへ遷移
- 管理画面の「ブラウザで開く」も動作

## リリース受入

- バージョン2.7.5
- EXE・インストーラーのバージョン情報
- SHA-256生成
- Release Assets
- `v2.7.5`タグ
- GitHub Release公開
- 新版通知が最新版と判定

ユーザーからv2.7.5公開完了の報告を受領しています。公開後の新版通知画面は本監査時点で添付されていないため、文書では確認済みと断定しません。

## 合否基準

- 自動試験に失敗がない
- 実運用DB・MP3を意図せず変更しない
- 移行・復元にバックアップがある
- 利用者間のデータ漏えいがない
- 主要機能がPC・スマートフォンで動作
- 既知の未確認事項を明記する
