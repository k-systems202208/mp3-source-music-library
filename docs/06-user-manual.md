# 利用マニュアル

## 1. インストール

1. GitHub Releasesから`MusicLibrary-Setup-2.7.0-x64.exe`を取得します。
2. 実行します。コード署名がない場合はWindows SmartScreenが表示されることがあります。
3. 旧版がインストール済みでも、通常はアンインストールせず上書きします。
4. インストール前に起動中の自宅音楽ライブラリを停止します。

## 2. 初回起動

1. スタートメニューから「自宅音楽ライブラリ」を開きます。
2. 「変更」でMP3が保存されているフォルダを選びます。
3. 「ライブラリを開始」を押します。
4. 初回走査が完了するとブラウザが開きます。

MP3はコピー・移動・書換えされません。

## 3. 管理画面

| 操作 | 内容 |
|---|---|
| 音楽フォルダ「変更」 | 参照するMP3フォルダを変更 |
| ライブラリを開始 | 走査後、サーバー起動 |
| ブラウザで開く | ローカルオーナーとして新しいブラウザを開く |
| 停止 | サーバー停止 |
| データ保存先を開く | `%LOCALAPPDATA%\MusicLibrary`を表示 |
| 外部接続をかんたん設定 | Tailscale Serveを設定 |
| 外部URLを開く | 保存済みHTTPS URLを開く |
| 外部接続を停止 | Tailscale Serveを停止 |

管理画面を閉じるとローカルサーバーも停止します。

## 4. ブラウザ画面

- 曲、アーティスト、アルバムのタブ
- 検索
- 索引
- ドリルダウンとパンくず
- 英数字タイトルのみ
- 訂正済みのみ
- お気に入りのみ
- 曲名・アーティスト名補正
- プレーヤー、シャッフル、リピート

## 5. 現在の利用者

右上の利用者チップを押すと識別状態を確認できます。

### ローカルPC

管理画面から開いたブラウザは「オーナー（オーナー）」と表示されます。URLを直接入力しただけではオーナーCookieがない場合があります。その場合は管理画面の「ブラウザで開く」を使用してください。

### Tailscale

Tailscale Serve経由では、Tailscaleログイン単位の利用者名が表示されます。初回アクセスで利用者プロフィールが作成されます。

### 匿名

利用者を識別できない場合も検索・再生できますが、★と再生回数は保存されません。

## 6. お気に入りと再生回数

- ☆を押すと★になります。
- ★を押すと解除します。
- 「★ お気に入りのみ」で現在の利用者だけのお気に入りへ絞り込みます。
- 曲を再生すると現在の利用者の再生回数が増えます。
- 別利用者の回数・お気に入りとは混ざりません。

## 7. 本人のTailscaleアカウントをオーナーへ関連付ける

この操作は、自宅PCのオーナーと、外出先で使う本人のTailscaleプロフィールを同一人物として扱うために行います。

1. 自宅PCで右上の利用者画面を開きます。
2. 「関連付けコードを発行」を押します。
3. コードをコピーします。
4. 本人のスマートフォンをTailscale経由で開きます。
5. 「本人のTailscaleアカウントを関連付ける」へコードを貼り付けます。
6. 自宅PCへ戻り、表示名、ログイン名、統合対象件数を確認します。
7. 本人であることを確認して承認します。

再生回数は合算、お気に入りはどちらかが★なら維持されます。異なる評価が両方にある場合は安全のため中止します。

コードや利用者情報が写った画面をSNS等へ公開しないでください。

## 8. 家族利用者を停止・再開する

1. 自宅PCのローカルオーナーで利用者画面を開きます。
2. 対象利用者の「利用を停止」または「利用を再開」を押します。

- オーナーは停止できません。
- Tailscale経由のオーナーは一覧閲覧だけ可能です。
- 停止されたTailscale利用者は匿名扱いとなり、個人状態を更新できません。

## 9. 外出先から利用する

1. PCとスマートフォンへTailscaleをインストールします。
2. PCで管理画面の「外部接続をかんたん設定」を実行します。
3. TailscaleログインやServe許可が求められた場合は本人が操作します。
4. 完全なURLをスマートフォンで開きます。

```text
https://PC名.tailnet名.ts.net/music-library-search.html
```

Wi-Fiを切り、モバイル通信＋Tailscaleで確認します。

## 10. 保存場所

```text
%LOCALAPPDATA%\MusicLibrary
```

重要な項目:

- `library.db`
- `Backups`
- `.artwork-cache`
- `Logs`
- `config.json`
- `remote-url.txt`
- `library-diagnostics.json`／`.csv`

## 11. 更新

- 起動中のアプリを停止
- 新しいインストーラーを上書き実行
- アンインストールは不要
- 初回起動時の移行前に専用DBバックアップを作成

## 12. アンインストール

Windowsの「インストールされているアプリ」から削除できます。安全のため、利用者データとMP3は自動削除しません。

## 13. 注意

- PCが停止・スリープ中は利用不可
- Funnel・ルーターポート開放は使用しない
- 接続URLを一般公開しない
- 市販音源を第三者へ配布するための機能ではない
- 260文字前後を超える長いパスは読み取りエラーになる場合がある
