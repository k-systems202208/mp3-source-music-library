# トラブルシューティング

## 1. ライブラリが開始しない

確認:

- 音楽フォルダが存在する
- フォルダへ読み取り権限がある
- `%LOCALAPPDATA%\MusicLibrary\Logs`の最新ログ
- `library-diagnostics.json`／`.csv`
- 既存のアプリプロセスが残っていない

## 2. `Errors`が表示される

診断ファイルの`category`と`message`を確認します。

### `mp3_read_error`＋`FileNotFoundError [WinError 3]`

ファイルが実在していても、フルパスが長すぎる場合があります。特に音楽フォルダ自体が深く、アルバムフォルダ・曲名が長い場合に発生します。

対処:

1. 音楽フォルダを`C:\Music`等の浅い場所へ移す
2. 極端に長いフォルダ名・ファイル名を短くする
3. Windowsの長いパス設定を確認する
4. 再起動後に再走査する

ファイル名変更前にバックアップし、移動検出が一意に成立することを確認してください。

## 3. 右上がオーナーにならない

- 管理画面の「ブラウザで開く」を使用する
- 古いタブではなく新しく開いたタブを確認する
- Cookieを全面禁止していないか確認する
- サーバー再起動後は管理画面から開き直す
- URLを直接入力しただけでは一時トークン交換が行われない

## 4. Tailscale経由で匿名になる

- Tailscaleアプリが接続済みか
- URLが`https://...ts.net/music-library-search.html`か
- Serveが有効か
- FunnelではなくServeか
- タグ付きデバイス等、利用者ログインヘッダーがない接続ではないか
- Tailscaleを経由せずLAN URLを開いていないか

## 5. お気に入りを押せない

右上が匿名の場合、誤った利用者へ保存しないためボタンを無効化します。ローカルでは管理画面から開き、外部ではTailscale URLを使用してください。

## 6. 再生回数が増えない

- 現在の利用者が識別されているか
- 対象利用者が停止されていないか
- 曲が`is_available=1`か
- ブラウザ開発者ツールで`/played`が401／403／404でないか

## 7. 利用者を停止できない

- 状態変更はローカルオーナー限定
- Tailscale経由オーナーは一覧閲覧のみ
- オーナー自身は停止不可

## 8. 関連付けコードが通らない

| 表示 | 原因候補 |
|---|---|
| 見つからない | 入力誤り、再発行で旧コード無効 |
| 期限切れ | 既定5分経過 |
| 別の利用者が確認待ち | 同じコードを他アカウントがclaim |
| 確認対象が一致しない | 画面表示後に候補が変化 |
| 評価競合 | 両側に異なる評価 |

新しいコードを発行し、表示名とログイン名を再確認してください。評価競合は自動解決しません。

## 9. schema 5移行に失敗する

- `library-pre-v2.7.0-*.db`が作成されているか
- ディスク空き容量
- DBを他アプリで開いたままにしていないか
- オーナーが複数存在する開発DBでないか
- `PRAGMA integrity_check`／`foreign_key_check`

移行失敗後にDBを手作業で編集せず、バックアップとログを保全してください。

## 10. 外部接続を有効にできない

- Tailscaleのインストール
- Windows右下のTailscale UIでログイン
- Serveの管理者同意
- `tailscale.exe`が見つかるか
- Tailscale backend state
- PCの時刻ずれ

## 11. 曲が途中で止まる／シークできない

- PCがスリープしていないか
- モバイル回線の品質
- Tailscale接続状態
- MP3自体が破損していないか
- Range要求への応答を開発者ツールで確認

## 12. SmartScreenが表示される

コード署名されていないインストーラーでは「不明な発行元」と表示される場合があります。GitHub Releaseの正式なファイル名とSHA-256を確認してください。

## 13. ビルドで長いパスエラー

PyInstaller hooksのファイル名は長いため、ビルドパッケージを次のような短い場所へ展開します。

```text
C:\ML270Build
```

`.venv-build`を削除して再実行します。必要に応じてWindows Long Pathを有効化します。
