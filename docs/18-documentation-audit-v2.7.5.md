# v2.7.5 全文書監査報告

## 監査日

2026-08-03

## 対象

- ルートREADME、更新概要
- `docs`配下の現行設計・運用文書
- `windows-installer`のREADME、Release Notes、配布文書
- v2.7.5 RC2ソース
- v2.7.4長パス実機結果
- v2.7.5プレイリストプレビュー・RC2ビルド結果
- ユーザーが共有したPC・iPhone実機画面
- ユーザーによるv2.7.5公開完了報告

## 主な発見

1. ルート文書の多くがv2.7.0／schema 5だった
2. v2.7.1～v2.7.5の主要機能が未反映だった
3. API・DB一覧が現行ソースより古かった
4. Windows文書にDraft／pre-release前提の表現が残っていた
5. 文書索引が未作成の統合サマリーを参照していた
6. RC／Phase文書と現行正式仕様の境界が弱かった
7. 実機値が製品固定値に見える箇所があった

## 実施した修正

- 現行版・schema・公開日を統一
- APIとDBをソースに合わせて更新
- PWAキャッシュ境界、長パス内部表現、起動認証を明記
- 利用者別プレイリストの所有権と削除範囲を明記
- 公開済み状態へRelease文書を更新
- 長パス・起動認証の正式サマリーを追加
- 実機値を「確認環境」と明示
- 履歴文書を改変せず分類
- Markdownリンク、末尾空白、EOFを検査対象化

## 根拠上の留保

- v2.7.5公開完了はユーザー報告で確認
- 公開後の新版通知画面は未提供
- 8,480曲、7,708アートワーク、201長パスは確認環境の値
- 将来候補は実装を約束しない

## 変更しない対象

- アプリソース
- DB・設定・MP3・アートワーク
- 公開済みタグ
- GitHub ReleaseとAssets
- 過去バージョン、RC、Phase文書の本文

## 結論

現行の入口文書、設計、API、DB、利用、運用、試験、公開、Windows配布文書をv2.7.5／schema 7へ揃えました。履歴資料は履歴として残し、現行仕様との参照経路を文書索引で明確化しました。
