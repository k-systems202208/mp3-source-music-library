# アプリ仕様書

## 製品情報

| 項目 | 内容 |
|---|---|
| 製品名 | 自宅音楽ライブラリ |
| バージョン | 2.7.6 |
| DBスキーマ | 7 |
| 対応OS | Windows 10／11 64bit |
| 音源形式 | MP3 |
| UI | Windows管理画面＋ブラウザ＋PWA |
| DB | SQLite |
| 外部接続 | Tailscale Serve |

## ライブラリ生成

- 選択フォルダーを再帰走査
- MP3をコピー・編集しない
- ID3タグ、ファイル名、フォルダー名からメタデータ生成
- 埋め込み・外部アートワークに対応
- 差分走査、キャッシュ、移動・改名検出
- Windowsの260文字以上のパスに対応
- 走査結果とエラーを診断ファイルへ出力

## 検索・ホーム

- ライブラリホーム
- 最近再生、お気に入り、よく聴く曲、最近追加
- 曲、アーティスト、アルバム表示
- アーティスト→アルバム→曲のドリルダウン
- キーワード、アルファベット、五十音、漢字・その他索引
- お気に入りのみの絞り込み
- ページングと並べ替え
- オーナー限定の曲名・アーティスト表示変更

## 再生

- HTML AudioによるMP3再生
- HTTP Byte Rangeとシーク
- 前へ、次へ、シャッフル、全曲リピート、1曲リピート
- プレイリスト全曲再生
- プレーヤーのアーティスト名・アルバム名から該当一覧へ移動
- サーバー側の再エンコードなし

## 利用者別機能

認証済み利用者ごとに次を保存します。

- 再生回数
- 最終再生日時
- お気に入り
- スキン
- プレイリストと曲順

匿名接続では保存しません。

## プレイリスト

- 作成、名称変更、削除
- 曲カードから追加
- 同一プレイリスト内の重複防止
- 曲順の上下移動
- 曲をプレイリストから外す
- 個別再生、全曲再生
- 他利用者のプレイリストを取得・更新できない
- プレイリスト削除時もMP3と曲レコードは削除しない

## スキン

利用者ごとに次の6種類を保存できます。

- ライブラリー
- ミッドナイト
- ネオン
- サイバーパンク
- キャンディー
- モノクローム

## バックアップ・復元

- ローカルオーナーが手動バックアップを作成
- DB整合性と対応スキーマを検査
- 復元は起動中DBへ直接上書きせず、次回起動時に適用
- スキーマ7ではプレイリストも対象
- 更新前の自動バックアップを作成

## 新版通知

- GitHubの公開済みReleaseを確認
- プレリリース設定を含む最新版判定
- 1日1回の自動確認と手動確認
- 自動ダウンロード・自動インストールは行わない
- 確認失敗は検索・再生を妨げない

## PWA

- manifest、専用アイコン、standalone表示
- iOS／Androidのホーム画面追加案内
- safe areaとモバイル操作サイズ
- 利用者別スキンに合わせたテーマ色
- キャッシュ対象は画面シェルのみ
- MP3、API、DB、バックアップ、アートワーク、認証情報はキャッシュ対象外
- オフライン再生は非対応

## 管理画面

- 音楽フォルダー選択
- ライブラリ開始、停止、ブラウザ起動
- データ保存先を開く
- Tailscale導入・Serve設定案内
- URL表示・コピー
- 起動中終了の確認

## 非機能仕様

- 既定ポート8765。競合時は空きポートを利用
- HTML、API、JSONは`Cache-Control: no-store`
- Service Workerは更新可能なシェルキャッシュ
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: same-origin`
- DB・設定・ソース等の静的配信を拒否
- 期待されるブラウザ切断をサーバー障害として扱わない
- DB操作はトランザクションと外部キーを使用
