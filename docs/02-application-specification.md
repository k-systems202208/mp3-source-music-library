# アプリ仕様書

## 1. 製品情報

| 項目 | 内容 |
|---|---|
| 製品名 | 自宅音楽ライブラリ |
| バージョン | 2.7.0 |
| DBスキーマ | 5 |
| 対応OS | Windows 10／11 64bit |
| 音源形式 | MP3 |
| UI | Windows管理画面＋ブラウザ |
| データベース | SQLite |
| 外部接続 | Tailscale Serve |

## 2. 機能仕様

### 2.1 ライブラリ生成

- 利用者が選択したフォルダを再帰走査
- MP3を別フォルダへコピーしない
- タグ、ファイル名、フォルダ名からメタデータ生成
- 埋め込み・外部アートワーク対応
- 差分走査、キャッシュヒット、移動検出
- 読み取りエラーの診断出力

### 2.2 検索・表示

- 曲、アーティスト、アルバム表示
- アーティスト→アルバム→曲のドリルダウン
- パンくず表示
- キーワード検索
- A～Z、あ～わ、漢字、その他の索引
- 英数字タイトルのみ、訂正済みのみ、お気に入りのみ
- 80件を既定とするページング、最大200件
- 曲順、タイトル、再生回数等の並べ替え

### 2.3 表記補正

- 曲名補正を曲単位で保存
- アーティスト名補正をアーティスト単位で保存
- 空文字または`null`で補正解除
- 補正は元のMP3タグへ書き戻さない

### 2.4 再生

- ブラウザAudio要素でMP3再生
- Byte Range対応
- シーク、前後曲、シャッフル、全体リピート、1曲リピート
- サーバー側で再エンコードしない

### 2.5 利用者識別

- ローカル管理画面からの起動はオーナー
- Tailscale Serve経由はログイン名を安定識別子として利用
- 表示名変更では別利用者にしない
- 重複した識別ヘッダー、制御文字、不正URLを拒否または無視
- 識別不能な接続は匿名

### 2.6 利用者別状態

- 再生回数
- 最終再生日時
- お気に入り
- 評価（DB・移行・統合対象。v2.7.0の操作UIは未提供）

匿名接続は検索と再生を利用できますが、再生回数とお気に入りを保存しません。

### 2.7 利用者管理

- オーナーは利用者一覧を閲覧可能
- ローカルオーナーは非オーナー利用者を停止・再開可能
- Tailscale経由オーナーは一覧閲覧可能だが状態変更不可
- オーナー自身は停止不可
- 完全削除ではなく停止・再開を採用

### 2.8 オーナー関連付け

- ローカルオーナーがコードを発行
- Tailscale本人がコードを送信
- ローカル側へ候補の表示名、ログイン名、個人状態件数を表示
- ローカルオーナーが明示承認
- 個人状態を統合後、Tailscale識別情報をオーナーへ移動

統合規則:

| 項目 | 規則 |
|---|---|
| 再生回数 | 合算 |
| 最終再生日時 | 新しい方 |
| お気に入り | 論理OR |
| 評価 | 片方のみなら引継ぎ、同値なら維持、異値なら全処理中止 |

### 2.9 管理画面

- 音楽フォルダの選択・変更
- ライブラリ開始、ブラウザ起動、停止
- データ保存先を開く
- Tailscaleの導入案内、Serve設定、URL表示、停止
- 起動中に管理画面を閉じる場合の確認

## 3. データ移行

v2.6.3以前の`tracks`にある共通の再生回数・最終再生日時・お気に入り・評価は、schema 5初期化時にローカルオーナーの`user_track_state`へ移行します。

- 移行前バックアップ必須
- バックアップのSQLite整合性と件数を検査
- 1人だけのオーナーを保証
- 件数・値の一致を検査
- 外部キー整合性を検査
- 失敗時ロールバック

## 4. 非機能仕様

- 既定ポートは8765。使用中なら空きポートを選択
- API、HTML、JSONは`no-store`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: same-origin`
- 静的配信からDB、設定、ソース等を遮断
- 期待されるブラウザ切断はサーバー障害として扱わない
- 更新時に利用者データを保持
- バックアップは起動時1日1回に加え、移行・関連付け前に専用作成

## 5. 制約

- Windows向け
- ライブラリ走査対象はMP3
- 自宅PCが停止・スリープ・切断中は利用不可
- インターネット全体への公開用途ではない
- 一般的なパスワード認証やパスワード回復はない
- 長いWindowsパスで読み取りエラーになる場合がある
- コード署名なしの配布ではSmartScreen警告が出る場合がある
