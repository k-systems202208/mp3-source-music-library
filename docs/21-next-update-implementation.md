# v2.7.7の実装内容

更新日: 2026年8月4日
状態: v2.7.7としてリリース対象

## 実装した機能

### プレイリスト操作性

- 名前と曲順を維持した複製
- 同名コピーがある場合の安全な連番付与
- PCで曲番号をドラッグして並べ替え
- PC・スマートフォンで従来の上／下ボタンを継続
- 所有者本人だけが閲覧、複製、編集、削除可能

### アルバム表示名

- オーナーがアルバムカードから表示名を変更
- 同じアルバムIDの全曲へ一括反映
- 補正値を空にすると元の表示へ戻る
- MP3ファイルと埋め込みタグは変更しない

### 利用者表示名

- オーナーと家族ユーザーが自分の表示名を変更
- 空白、60文字超、制御文字を拒否
- Tailscaleから識別情報を再取得しても利用者が決めた表示名を維持
- 他の利用者の表示名は変更不可

### 管理・診断

- DB quick checkとスキーマ番号
- 利用者、識別情報、プレイリスト、登録曲数
- 最新スキャンと問題件数・代表例
- DB、音楽、バックアップ、ログの保存先
- バックアップ件数、容量、最新日時、復元予約
- 最新状態の再読み込みと診断JSONの保存
- オーナーだけが画面とAPIを利用可能

## APIとデータ

追加・拡張した主なAPI:

- `PUT /api/me/profile`
- `POST /api/albums/{id}/correction`
- `POST /api/playlists/{id}/duplicate`
- `PUT /api/playlists/{id}/tracks/order`
- `GET /api/diagnostics`

DBスキーマは7のままです。既存の`display_name`、`album_override`、`playlists`、`playlist_tracks`を使用するため、追加マイグレーションはありません。
